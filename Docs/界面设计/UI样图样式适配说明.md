# UI 样图样式适配

2026-10-28

本次按提供的九张样图统一界面外观：深蓝黑半透明面板、细边框、薄荷绿主操作、浅灰次要信息、圆角按钮、细线图标和圆形滑块。

## 布局约束

现有屏幕布局继续沿用：主菜单靠左，其他菜单沿用原居中矩形；实体信息在左上，收藏在左侧中部，添加基因在左下，控制栏全宽贴底。没有修改场景、Canvas 缩放参数、面板锚点或外层定位。参考图的右侧实体面板、紧凑底栏等构图不用于替换现有位置。

图层按钮保留原来的“矿脉、地形、气候”排列。实体摘要在原来的 175 高信息区内显示分栏数值及进度条。添加基因仍保留原来的单列滚动窗口。

## 覆盖范围

- 主菜单、存档列表、创建世界、加载、多人开发中页面、设置、暂停菜单。
- 基因树流程图、文件列表、选中节点、四类关系线和属性面板。
- 实体摘要、核心/扩展基因、添加/复制基因、收藏和模板槽。
- 时间、图层、环境参数、放置数量和实体操控提示栏。

## 资源与维护

- `Assets/Resources/UI/theme.json`：字体优先顺序、颜色、基因图标映射、摘要字段及图层顺序。
- `Assets/Resources/UI/Icons`：41 个透明背景 PNG 线条/操作图标，支持 UI 着色。
- `Assets/Resources/UI/Surfaces`：13 个九宫格表面，另有点阵、菱形节点和透明输入层纹理。
- `Tools/generate_ui_assets.py`：原始矢量绘制与 PNG 输出脚本；需要 Pillow。重复运行保留已存在的资源 GUID。
- `UIVisualTheme`：uGUI 的颜色、背景、按钮状态及图标装饰。
- `RuntimeMenuTheme`：IMGUI 菜单和工作台皮肤。
- `EntitySummaryView`：只读摘要，读取真实数值和真实上限；不改变实体属性。

九宫格背景与独立图标分开，避免悬停状态覆盖图标。装饰性图标不接收射线。高 DPI 菜单同时清理旧的 `scaledBackgrounds`，滑条沿用 Unity 原生输入处理。

## 验证入口

Unity 播放模式的启动菜单中执行 `Tools > Darwin Park > Validate Reference UI Style`。也可以使用批处理入口 `DarwinPark.EditorTools.UIStyleRegression.RunBatch`。

测试输出位于 `Artifacts/UIStyleReview`，包括 11 张真实界面截图、`result.txt` 和 `unity.log`。测试创建独立世界并清理自己创建的存档，不覆盖已有世界或基因配置。测试只在本次运行降低地形采样以缩短耗时；截图里的星球精度不能代表正式场景画质。
