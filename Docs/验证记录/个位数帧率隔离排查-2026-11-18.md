# 个位数帧率隔离排查

使用 1014 个活体的基础基因修复存档副本。运行时固定到现场报告最慢帧记录的镜头，2560×1385、D3D12、1 倍模拟速度，限帧 60。每组从同一份存档重新载入。测试环境关闭自然投放和全局变异，仍保留正常死亡与其余生命更新。每组采样约 5 秒，指标反映短窗口。所有诊断开关只在隔离项目使用。

## 主要来源

正常运行采样 35 帧，平均 144.19 ms/帧，P95 156.90 ms/帧，约 6.9 FPS。实际交付每秒 1.000 游戏秒，样本末无模拟积压。暂停平均 22.66 ms/帧。正常运行时常规脚本回调 76.95 ms/帧，固定步脚本回调 43.14 ms/帧，物理引擎求解 4.17 ms/帧，渲染提交 9.39 ms/帧，GPU 有效采样平均 10.87 ms。暂停样本出现无效的 RenderLoop.Draw 计数，排除它的平均值，保留墙钟帧耗时与正常运行指标。

Profiler 的 8 帧层级样本显示，调度入口包含的中枢、基因及其他行为摊在一次 Update 中，入口中位约 45.35 ms。重力入口每帧约执行 3962 次，中位约 37.01 ms，内含岸线和地面探针。两套指标包含关系不同，不能相加。典型慢帧每实体 2 次模拟小步、4 轮物理回调。地面探针的大量调用包含从缓存返回，并非每次都查碰撞体或发射射线。重力与地表安全网分别进入探针，命中缓存前仍会读取姿态与地形身份。使用整帧平均与 P95 判断。

存档中有 560 工匠、317 士兵、65 生殖成员、49 王后和 23 个无蚁群角色的实体。992 个活体有启用的行动基因，仅 3 个有启用的游泳基因。这里是高度活跃的陆地蚁群世界，静止实体合并仅覆盖十余名，不能代表静止千实体基线。

以正常首次为参考，中枢绕过减少 31.47 ms/帧，关闭地面回调减少 54.10 ms/帧。二者会改变实体行动并影响其他回调，差值不能相加或当作上线可直接回收的时间。关闭地面回调时 PhysX 仍消耗平均 2.97 ms/帧，说明该组取消的是实体脚本而非物理引擎。50% 渲染比例与同进程的恢复基准整帧只差 0.54 ms，虽然平均 GPU 时间下降到 4.00 ms。各运行组最终都为 993 个活体，实际模拟时间约 1 游戏秒/真实秒，末尾无积压。恢复基准与首次正常的均值不同，保留这个波动范围。

原始记录在 Artifacts/GeneRiverReview/Project/Artifacts/FpsIsolation，两个阶段日志为 Artifacts/GeneRiverReview/fps-isolation-final.log 和 fps-isolation-resumed.log。续跑完成并输出 PASS。生产游戏代码、本机正式配置和原存档均未因这轮隔离诊断而改动。

## 优化方向

- 第一优先减少同一物理步的地面与岸线调用。由重力给地表安全网传递已有探针结果，计算位置、地形版本或碰撞体状态变动时才重验。检查中枢写入与最终物理前岸线验证的重叠，最终护栏保留。候选验收仍需浅岸、小河与碰撞推挤回归。
- 同时减少每个模拟子步的中枢热路径。把普通目标重选和马达路径刷新与时间积分分开，让每个可交互主体继续更新伤害、冷却与生命。继续独立测实际游戏秒、活跃数量和决策延迟。
- 渲染提交在暂停时已经构成固定开销。后续可以通过新环境的渲染通道抓帧降低它，但短期仍优先回收模拟和接地时间。
