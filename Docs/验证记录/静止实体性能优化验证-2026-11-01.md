# 静止实体性能优化验证（2026-11-01）

本轮把之前的优化设计接入正式运行代码，解决全图扫描、幼体诊断日志和长帧补算相互放大的问题；不是只更新帧率标签。Unity 6000.3.14f1，独立项目测试，未停止或清空主工程。

## 已实施

- `EntityNeighborhood`：共享帧快照、生产者资格及竞争结果。保留真实距离、半径边界、自身排除和原竞争公式。出生/停用、生命跨零、表达重算、搬运/跟随和恢复位置后同步失效；换局清理引用。大范围食物压力查询复用紧凑记录，避免遍历大量空格。
- `GeneAuthorityCache`：按表达对象和逻辑挂载版本选择主行为，复制基因不重复生产或繁殖；表达事件先于新逻辑挂载也会正确失效。生命/反击/状态组件不再每子步重复查找。
- `EcologyDiagnostics`：默认关闭正常繁殖条件不足的逐实体日志。需要时在`Assets/Resources/Entities/ecology_performance.json`开启，按真实时间汇总原因；出生、死亡和异常日志仍保留。
- 材质：记录颜色读取共享材质，未受击个体不在Start就复制整套材质；取消通用引力为每个实体创建从未启用的泳光。尚未实现GPU实例化或显示代理。
- `StationaryBodyRest`：已接触真实地面的无移动能力实体可休眠，保留动态刚体与碰撞，不关掉实体/基因/代谢/环境模拟。外力、有效行动、传送、星球变化及地形数据/参数变化后恢复检查。出生下落和其他移动物体上的接触不能取得休眠豁免。
- `SimulationStepBudget`：每帧默认最多交付0.5模拟秒，剩余排队；恢复时最多按所选倍率1.5倍渐进追赶。日历、行动和代谢采用实际交付时间，暂停不增加积压。加载恢复已完成进度，不追算加载或离线时间。整数子步避免0.5连续减0.1产生第六轮浮点残差。
- 统计卡260×136逻辑单位，较340宽再缩短约24%；FPS过低保留小数，过载时显示实际模拟倍率和待算时间。

## 真实星球短时运行

由真实世界创建流程生成614402顶点地形，运行环境、物理、基因、代谢和UI；并非暂停空菜单。约2560×1496的独立编辑器后台窗口，与主编辑器并存。固定四基因、关闭阶段随机突变以便隔离复现，每档预热1真实秒后采样约4秒；各倍率单独清空测试时钟债务再开始，避免16倍积压污染下一轮1倍结果。

同时验证实际地表休眠、接触资格、地形参数变化失效、外力唤醒、获得行动后恢复，以及休眠实体被传送高空后的安全网恢复。800档末有469个体休眠，不要求正在落地/受环境影响的个体强行休眠。
