# 尸体识别、右键属性与第一页统计验证（2026-11-01）

## 原因与改动

士兵击败外群实体后，`ColonyResource.LeaveCorpse`生成深色球形尸体，原活体注销；资源创建时删除碰撞体。原右键只执行Physics.Raycast并查找DarwinEntity，因此尸体看起来像较深的实体，却无法查看。

- 尸体增加共享的暖色叉号标记并调整体色，来源仍为死亡资源，不重建成活体、不占存活实体数量。
- 右键通过`WorldInspectablePicker`把普通实体的物理命中与尸体/能量块的局部几何求交统一比较；遵守最近目标和地形遮挡，支持缩放和旋转。不为资源增加碰撞体、刚体、点光源或每帧拾取扫描。
- 资源打开360×206逻辑单位的紧凑只读面板，尸体明确显示“已死亡”、营养、搬运与归属；新击杀记录生前名称和体型并随原资源快照保存。旧档未记录的来源不编造。切换活体恢复原基因面板；移除资源或离开世界时关闭并释放选择引用。
- 地图实体总数、基因筛选、齿轮设置与清除按钮统一移回第一页，第二页不重复显示。
