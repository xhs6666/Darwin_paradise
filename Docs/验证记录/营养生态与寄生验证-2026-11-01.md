# 营养生态、寄生与界面修复验证

日期：2026-11-01。Unity：6000.3.14f1，Windows。

## 实现结果

- FPS背景默认18%不透明度，支持0完全透明；文字保持原颜色。
- 组合筛选、统计与随机生成下拉模板统一处理勾选图和滚动条，修复缺省精灵产生的白色/绿色块。
- 寿终、饥饿、环境与战斗死亡统一到一次死亡结算；按实际消化收入扣除尸体余量，满仓不丢营养，完全消化不产生空尸体。
- 工匠接收中立、本群与灭绝群尸体，独占领取并按余量交付为能量块；食腐不抢已领取资源，旧失效领取可恢复。
- 新增异养的寄生/消化状态和食腐出错分支。寄生幼体隐藏并只随宿主移动，安全吸取饱食度，成年/失效/宿主死亡恢复渲染和碰撞。
- 原寄生改为卵寄生，外来卵独立保存亲本后代基因与计时，不借用宿主基因或自身孕育状态。
- 行动食草倾向仅自动选择静止猎物，捕猎可选择移动猎物；正常自主猎食需消化食性。反击、手动命令与士兵工作保持原权限。
- 基因树一次性升级旧营养分支及旧卵寄生定义，保留迁移后的自定义连线；新定义和快照成对保存。
