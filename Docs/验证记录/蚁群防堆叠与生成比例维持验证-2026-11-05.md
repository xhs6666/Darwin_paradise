# 蚁群防堆叠与生成比例维持验证

## 实现与边界

同群空闲/跟随目的地此前直接指向王后或补给点中心，持续挤压可形成身体堆叠；通用地面射线又可能命中其他实体的头部。现在成员获得独立站位，进食在真实半径内停止接近，行动增加同群切向避让，地面只检测星球碰撞体。王后出生及专用配偶选择育幼圈空位，拥挤时保留孕育。

随机生成来源改成两列互斥方式：模板按保存的基因/数值复制；基因方式保证必有/必无，其余逐个随机。明确来源投放的初始实体跳过出生当帧的二次变异，后续成年阶段变异保持原流程。

维持规则按全部存活实体的当前比例计算补充量，分母包含即将新增的实体。超量只延长普通实体/王后的新孕育等待，不删除实体、不取消已孕育后代。规则、模板快照及等待进度随世界保存并同步给副本；旧档缺字段保持关闭，世界清理停用规则。完整互斥分区使用一个实体的精度稳定，拒绝目标总和超过100%的互斥规则。

## 验证结果

- `PopulationMaintenanceRegression.RunBatch`：最终44项通过。包含实际两列入口、规则界面保存、80次条件随机差异、真实批次生成、出生条件保持、10个不匹配实体按30%实际补5个、死亡后补充、暂停/数量上限/权限、磁盘重载及联机快照、普通和王后繁殖间隔、保留已孕育后代、旧档兼容、多规则稳定与冲突拒绝、清理后不重新生成。
- 物理回归把8名成年工匠初始置于王后同轴上方，运行300个0.02秒实际物理步并执行引力/真实行动逻辑。最终全部成员离开王后中心，球面距离约3.36～7.16；没有通过传送疏散。出生点检查无身体占位。
- `AntColonyRegression.RunBatch`：59项通过，保留分工、育幼、运输、补给及有性王后配偶流程。取食断言更新为实际进食半径，继续验证真实能量转移与运输完成。
- `EntityPanelMotionRegression.RunBatch`：48项通过，含更新后的第二页来源入口、实际模板批次、球面落点、取消与门控。
- `PopulationArchiveRegression.RunBatch`：91项通过，种群档案、颜色、透明度、谱系和孤雌生殖保持兼容。
- `PlayerBuildLogRegression.RunBatch`：17项通过，实际Windows非开发版构建成功，0错误、1条Unity Cloud未登录不上传原生符号提示。
- 解决方案编译0错误、0警告；新增脚本均有有效GUID及无BOM的UTF-8编码。
