# 行动基因与河流水纹验证（2026-11-18）

## 改动

行动分类恢复按原始基因值与状态中心的距离确定状态。值25为游泳，值61为两栖；缺失状态沿用原跳过规则。旧世界内嵌的显式状态标记不能重新启用行动下拉控件；其他分类的显式状态配置保持其原有语义。

基因卡片的悬停、双击和滚轮转交合并到GeneHoverSurface，去掉每卡额外的EventTrigger及回调条目。ScrollRect只在绑定时获取。禁用行刷新只检查当前基因；运行求值和只读检查共用GeneDefinition.ResolveState入口。水位查询共用一次球面坐标转换，避免重复atan2/asin。

河床第四版将默认下切深度从1.5乘以3，水位不变。原有版本1～3保持原计算；已有世界在界面点击“一键升级高原 / 河流 / 盆地（先备份）”后才重新生成第四版。倍率随地貌配置保存，接受1～8。操作沿用原完整世界备份流程，本轮没有操作玩家存档。

河湖顶点色携带真实水深，独立于裁岸掩码。海洋与河湖共用程序化三维波纹及时间动画；细节随屏幕导数过滤，河湖增加浅深颜色和波纹反光。水面不移动物理高度，仍只使用一个合并河湖网格和材质，不增加逐河段更新脚本。
