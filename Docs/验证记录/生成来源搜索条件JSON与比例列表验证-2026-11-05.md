# 生成来源搜索、条件JSON与比例列表验证

来源窗口统一使用主Canvas的原生主题按钮、InputField、下拉和滚动列表。“有／无”按钮互斥，以实际条件决定颜色。搜索变化只重建结果行，输入框保留焦点、光标和编辑状态。切页后预先准备本页字形再统一更新文字网格，避免动态字体图集扩展导致按钮和页脚缺字。

新增命名的“保存条件 JSON”按钮，每个条件原子写入 `templates/spawn-conditions/<编号>.json`；打开窗口重新读取，保留版本、ID和必有／必无基因的校验。条件库跨世界复用，已启用规则继续使用世界内来源快照。维持页自动列出模板、已存条件、当前未存条件和历史规则来源，显示条件说明及当前数量；显式启用后才开始调节，可逐行改比例、启停和移除。
