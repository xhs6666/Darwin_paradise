# 种群不透明度与孤雌生殖验证

## 实现

- 种群显示设置新增0%～100%范围不透明度，填色和外沿均使用单群数值；并集不重复叠加。范围透明度与实体身体颜色同步选项独立。
- 未单独设置及旧档缺字段时沿用外部 `populationFillOpacity`，单群设置随世界和低频联机档案保存。
- 新增 `gene_sexual → gene_parthenogenesis` 出错分支，默认连续5游戏日无合适配偶后启动单亲孕育。等待时长由外部 `parthenogenesisWaitDays` 调整。
- 普通实体与王后保留成年、有效表达、营养、数量上限、孕育和产后冷却规则。找到配偶时优先有性繁殖；工匠等分工不能自主繁殖。孤雌王后不自动复制配偶规避等待。
- 等待时长及孕育类型成对保存；Unity内联序列化得到的空配偶基因组归一为无配偶。旧树及定义增量迁移一次，之后保留用户编辑。

## 验证结果

- `PopulationArchiveRegression.RunBatch`：91项通过，包含不透明度默认/端点/非法值/真实Shader数据/独立种群/磁盘及联机快照，以及实际单亲孕育出生、等待和孕育中读档、优先配偶、幼年/老年/禁用/冷却/副本/营养/数量边界、王后和工匠分工、重复基因、卵生及基因树迁移。
- `AntColonyRegression.RunBatch`：59项通过，保留原有有性王后的专用配偶、分工及补给运输行为。
- `EcologyBalanceRegression.RunQuickBatch`：21项通过，覆盖相关生态边界与旧孕育迁移；本轮没有重复完整长时间群落模拟。
- 解决方案编译：0错误、0警告。
- `PlayerBuildLogRegression.RunBatch`：17项通过，实际Windows非开发版构建成功，0错误、1条Unity Cloud未登录导致原生符号不上传的提示；无新增Shader编译错误。
- 已查看实际设置页截图：RGB滑条、新不透明度、两个显示开关、保存及恢复默认按钮均可见。
