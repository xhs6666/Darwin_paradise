# 运行逻辑流程图验证

## 交付范围

`Docs/运行流程图/index.html` 为无需网络的交互维护手册。覆盖Assets全部286个C#脚本（245运行时、41编辑器/测试）和10个Shader/HLSL文件，共2,993个显式方法、构造、访问器、局部函数、回调和GPU函数。零方法的数据/枚举文件仍有目录与源码视图。另有12条人工核对的业务导航、模块依赖、脚本内方法图、调用/被调用关系、接口实现候选、场景/预制体静态挂载及源码行号。

Editor和Windows Player分别按真实Unity程序集建立语义模型，语义错误均为0。合并相同版本图后共2,996张唯一流程图，对应5,204个版本视图、27,739个控制块。场景/预制体静态挂载匹配到24个脚本。

编译器CFG表示局部分支、短路、循环、返回和不可达块；catch/finally的补充边明确标为示意。少量无独立CFG的声明/表达式回调标注语法视图，GPU按兼容控制结构展示。接口候选、委托注册、反射/字符串入口不被伪装成已确定的运行调用链。Packages/Library及Tools不属于游戏源码覆盖范围。

## 实际验证

- 原项目 `dotnet build Darwin_paradise.slnx --no-restore`：恢复本地构建缓存后，0错误、0警告。
- 独立文档工具编译：0错误、0警告；无需NuGet下载。
- 生成器25项独立源码自测通过，覆盖早返回、循环、switch、异常/finally、yield/await、局部函数、匿名回调及Editor/Player条件编译。定义async回调不会被误记为外层方法在此挂起。
- `validate.py`：139,398项检查通过，逐文件核对覆盖和规范化源码SHA256，核对全部图边、方法目标、接口链接、版本、场景挂载、GPU前向include与脚本分图。
- `browser-check.mjs`：17项实际浏览器检查通过，含中文/方法搜索、GPU筛选、方法控制流、步骤定位源码、版本差异、接口关系、数据文件、脚本关系图、全部2,996张图的有限布局坐标、最大211块方法的渲染、SVG/XML与Mermaid导出、900宽度显示。
- 已查看实际业务导航和死亡结算方法截图；字体、选择状态、判断分支和缩放工具可见。
- 同版本重复生成的manifest逐字节一致，证据为 `Artifacts/FlowDocs/reproducibility.txt`。

证据位于 `Artifacts/FlowDocs/validation.json`、`browser-validation.json`、`business-flow.png`、`method-flow.png`。一键更新入口为 `Tools/FlowDocs/Generate.ps1`；生成器自测与静态校验随更新执行。完整数据见手册内 `coverage.json`。
