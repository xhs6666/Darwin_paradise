# 千实体性能与水体地理验证

隔离的 Unity 6000.3.14f1 编辑器项目，1920×1080，实际渲染 Game 视口。用同一世界配置生成 1000 个具有行动、中枢、探测的活体。保留动态刚体和环境更新，关闭自然投放与全局变异以维持规模。每组采样 5 秒。此场景用于复现活动实体卡顿，数字随视角、电脑负载、实体组成和地形变化。

最终平均约 6.8 FPS。静止 1000 实体的独立基线为 14.8 ms/帧，不能代替 1000 活动实体的压力结果。GPU 帧耗时在活动样本约 9–13 ms，暂停也远快于运行。Unity 主线程记录到慢帧执行 12–17 轮物理重力回调，调整后最多 4 轮。固定步长仍为 0.02 秒，单帧最多补 0.08 秒物理时间。严重掉帧时物理少补走一些时间，统一模拟时钟仍沿用原有积压机制。

## 水体和气候

普通行动基因不再直接发放游泳速度。游泳基因提供水中推进，鳃仍单独负责水下呼吸。当前格式已有世界打开时补齐游泳定义和进化分支，已有实体不自动获得游泳基因。海洋测试模板包含游泳和水下呼吸。路线在缓存/取目标时复核真实水面，行进时检查海、河、湖的岸线，浅水不能被陆行单位当陆地。查询一次地面半径，同时用于干湿与坡度，判断浸没时直接采水位。

第五版地貌对近岸陆架逐渐过渡到深海盆，下切天然湖泊已蓄水的底部，原有河道下切继续生效。河湖采用场景深度和真水深混合，浅水可透出水底。已有世界使用“升级地貌和水深（先备份）”重建水系。种子 78031 的隔离对照海域采样为 0.642 → 0.929 个世界单位，43 个共同湖区采样点为 0.597 → 0.822。河道专项测得旧版 1.525 → 4.501。

气候生成在低分辨率预计算海陆分布、盛行风与南北半球偏转产生的表层洋流。沿岸对流影响海温。沿海季风随模拟季节改变方向，影响实体查询到的湿度和降水。使用球面插值，跨经线连续。气候底图使用年平均值，季风影响在游戏时间取样时叠加。模型为游戏近似，洋流不推动实体，也没有独立流向叠加图层。

编译零错误零警告，基因、水深、季风和着色器专项 31 项通过，地理导航及坐标 115 项通过，旧版地形 8 组逐位基准通过。实际场景视觉回归 17 项通过并输出河流近景。
