# 生态默认与建群保障

新世界默认启用生产者70%、移动实体30%的生态维持规则，基础数量为100（70个生产者、30个移动实体）。不足时通过现有随机生成服务补充，超量时减少新繁殖；世界实体上限继续生效。后台补充会保留正在进行的实体操控和放置预览。

## 已有世界怎么使用

打开底部第二页的随机生成窗口，进入“维持比例规则”，点击“应用生态默认项”。两条默认规则会整体校验后应用，已有其他自定义规则保留；比例或规则上限冲突会显示未应用，不做部分修改。可以单独改比例、停用或删除规则。

旧世界加载时沿用原规则列表，建群保障按配置生效。已经灭绝的种群保留原档案记录；默认生成用于建立新的生态，不改写过去的历史。

## 默认模板

生成来源页和比例规则页都提供这些基础模板：

|模板|用途|
|---|---|
|默认生产者 · 自养繁衍|静止阳光自养，带成长、无性繁殖、储粮、修复和环境适应。|
|默认移动实体 · 消化取食|带行动、消化异养、无性繁殖、储粮、修复、环境适应及能量块利用。|
|蚁群创始王后 · 无性繁殖|具备种群、行动、繁殖和储粮等建群所需基因，可用于手动投放新蚁群。|
|移动清道夫 · 食腐回收|带食腐、行动、无性繁殖、储粮和能量块利用，供手动选择。|

前两个模板对应启用的70/30规则。王后与清道夫作为额外生成来源列出，用户可按需投放或自行配置规则。

默认生态规则按实体实际表达能力统计：生产者沿用游戏“静止自养”的判定；移动者按有效移动能力判定。王后、工匠和发生其他基因变异的实体也能正确归类。两类共享“生产者＋移动者”的分母；没有产能、也不能移动的特殊个体单独保留，不让这两条100%分区反复补充。普通的模板/必有必无规则仍按原来的来源条件统计。

## 新王后怎样建立补给链

- 定居的新王后在小型建群阶段默认领取一次64点育幼储粮。领取标志、已发数量和运输状态随实体存档保存，重新载入和基因重算不重复领取。
- 缺工匠时，王后优先繁殖工匠，直到群内有2名工匠；仍支付原有繁殖食物和孕育时间。这个阶段优先建立补给链，免于全局移动者比例超量造成的繁殖等待。
- 工匠成年前，王后临时执行原有采集、搬运和送达流程。2名成年工匠到位后，王后送完手中货物，再恢复专职繁殖。
- 默认生产者的自动补充优先寻找活动区内植物不足的定居蚁群，补到配置的局部目标8个。投放仍需命中真实地表并符合陆地要求。

创业储粮是有限初始物资。寿命、饥饿、攻击、环境适应和实体上限都继续生效；长期延续仍依赖生产、采集、繁殖与正常遗传。

## 外部配置

编辑游戏目录的`config/ecology_defaults.json`。仓库提供该文件；发布版缺失时从内置默认复制生成。支持中文行注释、块注释和UTF-8文本。

|参数|默认值|作用|
|---|---:|---|
|enableNewWorldRules|true|新世界自动启用默认生态比例。|
|minimumPopulation|100|默认基础数量，按两个比例分配保底。|
|producerRatio / mobileRatio|0.7 / 0.3|两个比例之和需为1。|
|enableFoundingSupport|true|启用有限创业补给、工匠优先及王后临时采集。|
|minimumWorkers|2|建群优先补齐的工匠数量。|
|foundingFood|64|新王后的一次性育幼储粮。|
|maximumFoundingMembers|4|只对尚处小型起步阶段的种群发放初始储粮。|
|localProducerTarget|8|默认生产者优先补充到蚁群附近的局部目标。|
|plantSpacing|3|优先投放时避开现有实体的间距。|
|templates|四种模板|各模板的完整基因、数值与阶级。|

新世界使用修改后的文件。已有世界保存自己的生态配置快照；在维持比例页显式点击“应用生态默认项”会重新读取外部配置并应用。联机时由房主校验、生成和推进，客户端接收规则及低频配置同步。

相关文件：`EcologyDefaults.cs`负责默认项与配置，`EcologyMaintenancePolicy.cs`负责分类及投放偏好，`ColonyFoundingSupport.cs`负责建群交接，原采集、繁殖和地形生成入口继续承担实际执行。
