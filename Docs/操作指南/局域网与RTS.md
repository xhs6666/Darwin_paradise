# 局域网与 RTS

## 开放和加入

1. 管理员先进入一个单人世界，按 Esc，点击“对局域网开放”。
2. 选择端口及是否开启作弊模式，点击“开始开放”。默认端口为 47777，菜单显示管理员的局域网 IP。
3. 其他玩家在主界面点击“多人游戏”，填写管理员 IP、相同端口和自己的名称，点击“加入游戏”。
4. 加载完成后选择一个尚未被占用的实体开始游玩。普通成员只能在首次进入或所操控实体死亡后重新选择。

同一程序同时包含服务端和客户端。房主是唯一管理员；最多 8 名成员，容量可在 `Assets/Resources/Entities/lan_multiplayer.json` 修改。房主打开 Esc 菜单不会暂停整个对局。

## 权限

| 操作 | 管理员 | 普通成员 | 开启作弊的成员 |
| --- | --- | --- | --- |
| 选择未占用实体游玩 | 可以 | 进入或死亡后选择 | 可以更换 |
| 修改名称、基因值、添加基因 | 可以 | 禁止，控件只读或隐藏 | 可以 |
| 放置实体、模板、全星球随机生成 | 可以 | 禁止，生成页不可用 | 可以 |
| 修改世界参数、基因树、模拟时间 | 可以 | 禁止 | 可以 |
| RTS 指挥 | 未被其他玩家占用的实体 | 王后自己的种群 | 未被其他玩家占用的实体 |
| 开关作弊、关闭局域网 | 可以 | 禁止 | 禁止 |

作弊开放世界编辑能力，不产生第二名管理员。关闭作弊立即撤回成员的编辑权限。所有修改及指令都由服务端验证，隐藏按钮之外也有权限检查。

## 操控与 RTS

实体操控继续使用 WASD、左键攻击、空格跳跃；按住 Alt 唤出鼠标，松开恢复。P 启停模拟仅管理员及作弊成员可用。Q 吐出能量块仍要求自身营养利用基因生效并有足够营养，由服务端扣除实际能量。

按 R 进入或退出 RTS：左键拖出方框，Shift 追加选择，中键转动镜头，右键下达移动指令；右键可攻击目标时自动攻击。下方命令栏可以选择攻击、采集或守卫，再右键指定目标；“停止”立即停止。采集指令交给原有工匠运输系统，不会复制尸体或货物。

命令依照实际基因和角色开放：无有效行动能力的实体不能移动，王后和工匠不能使用战斗攻击，采集搬运只供工匠。普通成员操控王后时可以进入 RTS，框选及服务端指令都仅限该王后自己的种群。管理员也不能夺取其他玩家正在操控的实体。

## 保存与离开

房主统一运行模拟并保存世界，包括远端基因修改、实体及 RTS 指令。客户端使用内存中的世界副本，不把房主世界写入自己的存档目录；作弊成员在局内应用基因树也不会覆盖房主电脑上的任意文件。

成员可在 Esc 离开联机。房主关闭局域网后继续单人游戏，成员返回主界面；房主退出时同样结束房间。断线会释放所占实体，之后可重新加入。加载过程中断线会停止加载并清场。当前不提供房主迁移。

已完成同机两个独立 Unity 进程的真实 TCP 测试；尚未使用两台物理电脑验收局域网连接。
