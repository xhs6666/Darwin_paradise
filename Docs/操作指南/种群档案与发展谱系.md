# 种群档案与发展谱系

底栏第二页的“种群档案”提供“全部种群列表”和“显示配置”入口。第一页保留地图实体统计和实体筛选。普通联机成员也可在第二页查看档案，不需要创造权限。

## 完整列表与详情

左侧列出所有已记录种群，包含存活和已灭绝种群，支持按名称或编号搜索、状态筛选及分页。选择种群后，右侧可查看：

- **概览**：当前成员、历史峰值、成立或首次观察时间、累计成员增加和流失、来源与最近事件。成员增加/流失包括出生、死亡和迁移，不等同于纯出生/死亡统计。
- **基因**：携带人数、携带率、生效人数和生效率，可勾选只统计生效基因。重复携带同一基因的实体只计一次。扇形图按所有基因的携带/生效人次计算构成；每项图例另列该基因在群体内的携带/生效率，因此多个基因的携带率可同时为100%。柱状图显示人数。
- **年龄**：幼年、成年、老年人数与百分比，支持扇形图和柱状图；存活群体还显示平均寿命进度。
- **发展历史**：规模随模拟时间变化的图表、事件及采样明细。默认每10模拟秒记录一次，成员数变化会立即产生记录；暂停不重复制造相同历史点。
- **衍生种群**：显示由该种群发展出的新种群和后续世代，点击可跳到对应档案，也可返回来源种群。
- **成员**：分页浏览该种群全部当前存活成员，可定位具体实体。
- **显示设置**：红、绿、蓝滑条分别使用对应颜色，也可用`#RRGGBB`设置颜色、预览并保存；可单独隐藏种群范围和成员标记，也可恢复默认配色后保存。勾选“同步实体颜色”并保存后，该种群成员的身体外观使用种群配色；取消勾选并保存会恢复实体原色。此选项默认关闭，受击红色闪烁结束后恢复当前配色；新加入的成员同样适用。颜色、同步选项和显示状态随世界保存，联机由房主配置并同步。

打开档案时，单人模拟暂停，底层操作被屏蔽；关闭后恢复打开前的运行状态。联机中打开档案不暂停房间。Esc关闭窗口。

概览、事件、历史图表与采样明细的时间均显示为游戏内的“第 X 年 X 月 X 日”，与底栏日历一致；存档仍保留原始模拟时间。

## 来源和历史记录

蚁群繁殖个体实际离群建群时记录来源；种群状态变化后独立成群、非蚁群后代在外独立成群时也会记录。加入已存在的群体不会修改该群的来源。谱系可跨多代查看，灭绝群体的档案和最后存活基因/年龄分布继续保留。

旧存档没有此前的档案数据，只从本版本首次观察开始记录，并明确显示“此前历史未记录”。不会按位置、名称或相似基因推测过去的成立时间和来源。

历史采样默认最多512条，超出时压缩中间点、保留最早和最新记录；事件默认保留最近256条。容量及记录间隔由 `Assets/Resources/Entities/population_archive.json` 配置。实际历史、谱系、显示配置保存在世界存档的 `colony.population` 中，加载前检查非法采样和循环来源关系。
