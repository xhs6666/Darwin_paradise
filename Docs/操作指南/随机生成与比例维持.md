# 随机生成与比例维持

底栏第二页的“随机生成 · 全星球”中，点击“选择实体”打开两列来源界面。两种生成方式互斥：

- **左列：实体模板**。选择默认实体或已保存模板，完全使用模板保存的基因和数值，不附加随机基因。模板副本拥有独立的基因实例。
- **右列：基因条件随机**。为任意基因勾选“一定有”或“一定没有”；同一基因的两种条件互斥。未限定的其他基因及其数值逐个实体随机生成。同批实体会不同，而非复制一次随机结果。

点击“应用生成来源”回到底栏，填写数量并点击“随机生成”。来源窗口中的陆地范围选择会同步到底栏。默认单批10个，上限200个；“取消本批”停止当前生成，不删除已经生成的实体。按明确来源生成的初始实体不会在出生当帧再重抽变异，成年后的自然变异继续生效。

## 维持比例

点击“维持比例…”或来源窗口的“维持比例规则”，选择来源、填写目标百分比后新增规则。列表显示当前匹配数、存活总数和占比，支持启用、停用、编辑及删除；点击“新增规则”可另外配置下一条。默认最多保存8条规则。比例范围为0%到小于100%，100%在已有不匹配实体时不能靠有限次补充达到，因此不接受这一目标。

每条规则分别执行：

- **少于目标**：直接按该规则的来源在星球上补充实体。新实体同时增加分子和分母；例如已有10个不匹配实体，要达到30%，会补充5个，得到5/15。整数数量可能略高于目标。
- **高于目标**：延长匹配实体开始下一次孕育前的等待，普通实体和蚁群王后都适用。正在进行的孕育继续完成，现有实体不会被删除；营养、配偶、冷却、年龄和分工限制仍保留。
- **完整互斥分区**：例如“有行动”33.3%和“无行动”66.7%，按一个实体的精度稳定维持，避免两边追逐分母而反复补充。互斥规则的目标总和超过100%会被拒绝。

总数采用全地图存活并启用的实体。基因条件按“携带”判断，禁用或受抑制的基因仍算存在；模板规则按保存的基因、数值、复制强度、开关和缺失状态匹配，不按名称或血缘统计。自然变异后可能不再匹配原来的规则。

自动补充只在模拟运行时执行，受当前世界实体数量上限和实际地表条件限制；暂停时等待。单批补充有数量预算，分帧完成。完全空的世界默认先生成10个作为起始数量。若维持任务仍启用，“取消本批”之后恢复模拟时还会按规则检查；要停用长期维持，请在规则列表关闭开关或删除规则。

规则和繁殖等待随世界存档保存，切换世界时停止旧任务；旧档没有规则时保持关闭。清除全部实体会同时停用维持规则，避免立即重新生成。联机中由房主执行，管理员及开启作弊的成员可编辑，普通成员不能通过生成或规则编辑入口绕过权限。

## 蚁群站位

休息和跟随成员分散在王后或补给点周围，进入进食半径即可进食，不再全部冲向中心身体。移动时进行同群切向避让；地面检测只识别真实星球碰撞体。王后新生后代及专用配偶优先选择育幼范围内的空位，空间不足时保留孕育等待，而非继续向头顶叠加实体。

默认队形间距、避让和出生尝试次数位于 `Assets/Resources/Entities/colony_formation.json`；随机附加基因数量、补充预算、轮询模拟间隔及超量繁殖等待位于 `Assets/Resources/Entities/population_maintenance.json`。这些是工程资源配置；实际来源、比例和开关通过游戏内界面调整并保存在各世界中。
