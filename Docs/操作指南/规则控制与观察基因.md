# 规则控制与观察基因

## 第一页规则卡

底部控制栏第一页新增“规则控制”，与地图统计/筛选卡均为260×164。宽屏放在筛选右边；窄屏通过右上方“规则”展开同尺寸浮卡，位于筛选浮卡上方。第二页继续保留种群档案。

可修改“定时全局变异”开关、抽样百分比与每轮模拟秒数，点“应用并保存”后写入外部`config/gameplay.json`；已有中文注释、其他数值与未知字段保留，旧文件缺少新键时自动补齐。修改前读最新文件，以免覆盖在外部编辑的其他值，原文件保留`.bak`备份。`重载`重新读取外部文件。只读成员和联机副本不能绕过按钮直接执行保存。

默认10%、30模拟秒一轮；暂停和全局开关关闭时不推进，倍率会影响轮次对应的实际秒数。比例0到100%，周期1到86400模拟秒。比例和周期变化用于下一轮，已抽出的剩余名单继续按原名额处理；缩短周期时会保留已累计时间。卡片显示轮次、上轮实际抽取/总活体数以及剩余待执行人数。

## 每轮怎样变异

名额按当轮全部存活实体数×比例向上取整，例：100个选10个，525个选53个；0%不选任何实体。尸体不是活体，不进入分母。每轮无放回随机选取，不按注册顺序或近邻序号固定挑选。工匠等基因锁定角色、孵化中的卵、未启用基因计算的实体不进入候选；候选不足时实际抽取数减少。

每个选中身份调用一次真实变异入口，默认类型权重仍为数值出错90%、复制5%、缺失5%；环境压力只影响选中后偏向哪条已有基因。基础基因保护等规则可能使某次操作失败，因此抽样人数不等于保证所有抽中者都发生有效DNA变化。旧实体的`mutationChance`和旧近邻`mergedMutationFraction`字段仅保留兼容，不再决定自然变异。

每帧默认最多执行16个已选身份，余量留在队列。出生、成年和老年只登记生命阶段并更新属性，统一定时轮次之外不再额外抽签。世界保存记录累计计时、轮次、计数及剩余身份，读档后继续原名单；等待期间死亡或变为受保护角色者跳过，不补抽其他人。

## 观察基因

观察基因已加入基因库与基因树。可在实体基因编辑、基因条件随机生成中添加，模板方式仍严格沿用模板已有基因，不暗中改写旧个体DNA。

|状态|倾向|默认行为|
|---|---|---|
|视野范围|接收更大范围的信息|以基因视野属性×2计算范围，约0.6模拟秒收取一次新信息；追击采用上次观测坐标|
|注意力|持续跟踪已知目标|以基因视野属性×0.8计算范围，约0.1模拟秒更新新目标列表；已知目标坐标每帧可更新|

视野属性曲线默认20到40：基因值25的“视野范围”约50距离，值75的“注意力”约28距离。定义可在基因工具中调整并随世界保存；倍率/刷新周期配置在`Assets/Resources/Entities/observation.json`。

自主行动只使用视野内投递的信息，并继续检查同群、体型、食性、领地和隐藏寄生资格。出视野、停用或死亡目标不能继续定位。禁用已有观察基因会撤销视野；没有观察基因的旧实体保持原感知范围，避免升级后全体失明。明确点选的手动攻击/RTS攻击指令保留原操作语义。
