# 主界面与基因树工具

启动 SampleScene 后进入主界面。单人游戏进入存档列表，可以选择已有存档或创建新世界。游戏中 Esc 打开菜单，F10 不执行返回或退出。设置支持主音量、全屏和画质，保存后下次启动读取。多人游戏可输入管理员的局域网 IP 和端口，加入后选择一个实体游玩；详见[局域网与 RTS](局域网与RTS.md)。世界创建和存档细节见[主界面与存档流程](主界面与存档流程说明.md)。主菜单默认宽 320，按钮高 58，减少横向拉长。

## 第一人称
双击实体后进入锁定第一人称，WASD 移动、鼠标转向、左键攻击、空格跳跃、Tab 返回星球。Esc 打开暂停面板，返回游戏后保留操控目标。滚轮不再拉远。自身模型暂时隐藏但仍有碰撞，退出恢复。近身攻击保留原攻击距离、行动基因与冷却限制。

操控中按 P 启动或暂停模拟，按住 Alt 释放鼠标、松开恢复操控；不再显示新增的操控栏和补给按钮。拥有生效“营养利用基因”且有足够营养时，按 Q 消耗自身营养吐出通用能量块，默认基因值 50 时吐出 5 能量。E 免费补给已取消，自动吸收保留。基因失效、营养不足、暂停、按住 Alt 或输入框获得焦点时 Q 无效。

## 工作台

实体信息面板默认宽 520、高 560，保留滚动与小窗口边界适配。底栏第二页的“随机生成 · 全星球”宽 240，点击“选择实体”打开两列界面：左列完全按模板生成，右列选择基因必有/必无且其他基因随机。默认仅陆地，可切换全部地表；每批默认10个、最多200个，分帧完成，支持取消本批。新增比例维持：不足时直接生成，超量时延迟新孕育；详见[随机生成与比例维持](随机生成与比例维持.md)。切换底栏页面时任务继续，单人打开覆盖菜单会暂停未完成任务，切换世界则停止。联机时只有管理员和作弊成员可生成；房主打开菜单不会阻塞成员请求。

- 主界面 → 工具 · 基因树编辑器。
- 左侧读取内置和已保存的 JSON 基因。输入文件夹路径后点“读取 JSON”，可合并该文件夹内配置（文件名必须等于 id）。
- 从左侧拖到右侧画布；拖动已有节点调整位置。普通基因为方框，出错基因为菱形。
- Shift 左键源节点，再点目标节点，建立下级进化关系。
- 右键节点，右侧选择向下进化、侧向出错、红色抑制或绿色促进，再点目标节点连接。
- 右侧“菱形：出错基因”可更改节点外框。出错连线自动将目标显示为菱形。
- 右键连线可设置类型、数值或删除。进化/出错数值是目标的相对选择权重；抑制/促进数值沿用 coefficient 单位（源基因值 × coefficient ÷ 1000）。
- 右键节点可编辑名称、属性最小/最大值、状态中心值；高级 JSON 保留完整编辑能力。
- 属性区的“实体状态标签”从注册表自动列出，可给基因授予活动状态；不替换基因本身的巡逻/警戒等倾向。状态条件、阈值和迁移配置在 `entity_states.json`，保存时与基因一起导出。详见[实体状态注册表开发说明](../开发设计/实体状态注册表开发说明.md)。
- 缩小/放大按钮与画布滚轮控制 15%～200% 缩放，中键拖动平移；“适应全图”一次查看所有节点，“100%”恢复原比例。缩放后节点选择、拖动、连线和拖入沿用图坐标。
- 层级列表与流程图共用同一份数据。Esc 取消正在建立的关系。
- “保存并应用”提交当前数值并保存；“重新读取”只在无未保存修改时执行；“放弃修改”恢复磁盘版本。

## 保存与游戏读取
默认目录显示在工具顶部：游戏目录下的 mods/Default（编辑器中为工程根目录下的 mods/Default）。
Genes 子文件夹存储每个基因的 JSON，tree.json 存储节点位置、菱形标记及四种关系。游戏启动自动读取；相同 id 的自定义定义覆盖内置定义。保存并应用会重新加载基因库并重算现有实体。
复制变异优先沿向下进化关系选择新基因，数值出错变异可沿侧向出错关系切换定义，原有90/5/5类型概率保持不变。红线和绿线分别映射抑制与促进表达。
