# 达尔文乐园：新手入门指南

适用版本：2026-11-01 当前功能，Windows 键盘与鼠标操作。

你可以在星球上投放生命、观察基因和环境怎样影响生存，也可以进入某个实体的视角亲自行动。第一次游玩，先完成“创建世界 → 投放 → 查看 → 操控 → 保存”这条路线，再尝试蚁群、RTS和联机。

本文以默认配置为例；使用自定义基因或旧存档时，请以游戏面板中的实际状态和权限为准。

## 1. 第一局先完成这六件事

### 第一步：创建自己的世界

1. 主界面选择 **单人游戏 · 存档**，再选择 **创建新世界**。
2. 填写世界名称和种子。种子可以是整数或文字；第一次可以保留默认环境参数。
3. 点击创建，等待加载进度结束。
4. 进入后按 **P** 暂停，先熟悉界面。若快捷键没反应，先点击输入框外的空白位置。

新世界不会因为菜单背景里出现了星球，就已经开始模拟。真正进入世界后，底栏会显示日期和播放/暂停按钮。

### 第二步：投放第一批实体

底栏左上方的左右箭头用于切换两页。点击右箭头进入第二页，找到 **随机生成 · 全星球**。

1. 模板选择“默认实体”，先输入 **20**，范围保留“仅陆地”。
2. 点击 **随机生成**，等待数量提示完成。生成按批次进行，可以点击“取消”停止后续生成。
3. 按P继续，以 **1倍速度**观察。

这20个体用于熟悉操作，不是完整生态循环的数量配方。随机生成会分散到星球各处，并不保证都在当前镜头附近。

想指定落点时，点击第二页的“默认生成”或模板槽，再到地表左键放置；也可以把槽位拖到地表。点击式放置可以连续进行，**右键或Esc取消放置**。右键生成槽可设置每次放置的数量。

### 第三步：找到并查看一个实体

- 在星球视角中，**左键拖动**旋转视角，**滚轮**缩放。
- 在未放置、未进入RTS时，**右键活体**打开实体属性面板。
- 查看生命、饱食度、体型、生命阶段和当前活动；把鼠标移到基因行上，可查看该基因贡献的属性和说明。
- 点击标题旁的星形按钮收藏。第二页的“收藏列表”可以帮助你再次定位它。

默认实体拥有生长、繁殖、营养方式和环境适应等基础基因，通常依靠阳光自养。**没有有效移动能力时，保持静止是正常行为。**领地、种群等进阶谱系也可能提供行动能力，所以判断时要看实际表达和状态。

### 第四步：体验一个能移动的个体

单人游戏中可以编辑普通实体的基因。建议先暂停，再做一个小练习：

1. 右键打开一个普通实体的面板，点击“扩展基因”旁的 **＋**。
2. 选择 **行动基因**，输入数值后按回车或点击其他位置提交。
3. 在默认配置、没有额外抑制时，行动基因设为 **25** 通常对应“食草”。再添加 **异养基因**并设为 **75**（消化），才可击败附近静止实体后吸收其营养；只把父级营养方式设为80还不能代替独立异养能力。以面板显示的状态和是否生效为准。
4. 在它附近投放一些默认自养实体作为食物来源，再恢复1倍运行，观察饱食度降低后的觅食。
5. **双击这个活体**进入实体视角，尝试WASD移动、鼠标转向、空格跳跃；按Tab返回星球视角。

获得行动能力后不能继续假定它能靠原有方式自养。是否能移动、进食和攻击，还受基因表达、体型、环境及当前状态影响。

### 第五步：看懂地图统计

切回 **第一页**，右侧“地图实体统计”显示：

| 项目 | 含义 |
| --- | --- |
| 实体总数 | 全地图存活实体数，包含镜头外个体 |
| 幼年／成年／老年 | 当前存活个体的生命阶段分布 |
| 基因筛选 | 选择一个基因，查看相关数量 |
| 携带 | 有这个基因的实体数；同一个体的复制基因只计一次 |
| 生效 | 当前实际表达该基因的实体数 |
| 占比 | 携带个体占全体存活实体的比例 |

“携带”多于“生效”通常说明部分个体的基因被禁用或受到抑制。筛选用于观察，不会只让筛选中的实体运行。

### 第六步：保存并离开

按 **Esc** 打开菜单，选择 **保存并返回主界面**。之后从单人游戏存档列表再次进入。

默认每120秒自动保存；正常退出也会尝试保存。保存失败时先查看提示，不要把强制关闭程序当作保存操作。联机世界由房主统一保存。

## 2. 先分清这三类物体

| 外观或标记 | 是什么 | 可以做什么 |
| --- | --- | --- |
| 普通实体模型 | 存活个体 | 右键查看属性；双击尝试操控，具体能力取决于基因和权限 |
| 暖色叉号、较深色球体 | 死亡后未被吸收的营养形成的尸体 | 右键查看死亡、营养和搬运信息；可由工匠运输或被食腐实体吸收，不计入存活总数 |
| 黄色发光块 | 能量或种群补给 | 右键查看资源信息；符合条件的实体可自动吸收 |

新产生的尸体会记录生前名称和体型。旧存档没有记录的字段会显示“旧存档未记录”。查看尸体不会把它变回活体。

## 3. 基因、营养和繁殖怎么理解

先记住三个区别：

- **有基因，不一定生效。**基因会相互促进或抑制，环境和角色也会改变表达。输入值后，检查实际状态、有效属性和提示说明。
- **饱食，不等于储备充足。**进食先补饱食度，溢出部分进入储存；繁殖会检查成年、储备和其他条件。
- **营养方式，不等于营养利用。**前者决定自养或异养等方式；独立的营养利用基因与通用能量块的吸收、吐出有关。
- **异养分为寄生和消化。**寄生幼体隐藏自身、跟随更大的宿主吸收饱食度，宿主显示“（被寄生）”，成年后脱离并独立消化取食。消化只在击败后结算，未吸收完的营养留下尸体；食腐是异养的出错分支，吸收尸体余量。
- **卵寄生属于繁殖。**它向宿主放入外来卵，宿主显示独立的卵寄生孕育状态，卵的后代基因来自亲本，与宿主无关。

普通繁殖通常需要成年及足够储存营养；有性繁殖还需要合适配偶。怀孕和产后休养需要时间，不能以“刚生成就没有后代”判断出错。实体上限已满时，已完成孕育的个体会等待空位。

同一实体的多个复制基因可能叠加表达，但生产、移动、繁殖等关键行为不会因此重复推进。士兵、工匠等固定分工的遗传基因受到锁定，无法像普通实体一样随意修改。

### 把喜欢的基因组合保存为模板

在实体面板顶部点击 **存为模板**。第二页的模板槽及随机生成列表可使用它，模板会跨世界和重启保留。

模板保存的是可再次生成的基因组合，**不是当前个体的完整游戏进度**。要保留它的年龄、营养、位置和孕育状态，应保存世界。

营养利用是储存基因出错演化的分支。想进一步调整基因的进化、促进或抑制关系，可从主界面进入“工具 · 基因树编辑器”，按[基因树工具说明](主界面与基因树工具说明.md)操作；这与只修改某个实体的基因值是不同的功能。

## 4. 实体视角操作

| 操作 | 功能 |
| --- | --- |
| 双击活体 | 进入实体视角 |
| WASD／鼠标 | 移动／转向 |
| 左键／空格 | 攻击／跳跃，受实际能力限制 |
| 按住Alt | 释放鼠标；松开后恢复操控 |
| P | 启动或暂停模拟；联机需要管理或作弊权限 |
| Q | 有生效营养利用基因且营养足够时，消耗自身营养吐出能量块 |
| Tab | 返回星球视角 |
| Esc | 打开菜单；返回后保留操控对象 |

暂停、按住Alt、正在输入文字或基因不满足条件时，相应行动可能不执行。当前没有E键免费添加能量块的功能。

陆地行动能力不等于游泳能力。进入水中后无法继续按陆地方式移动，并可能溺水。移动速度和跳跃也受体型及最大能力限制。

## 5. 学会管理规模和环境

### 给这个存档设置实体上限

第一页统计卡右上角点击 **齿轮 → 本存档游戏设置**，输入上限并点击“保存设置”。

- 默认上限为 **3000**，**0表示不限**。
- 上限同时约束投放、随机生成和繁殖。
- 降低上限不会删除已有个体；超过上限的旧存档仍会完整加载。
- 设置属于当前存档，与主菜单中的音量、画质设置分开。

第一页底部的 **清除全部实体** 会清除全地图实体并保存结果，**不按当前基因筛选范围清除**。需要保留进度时，先备份存档再使用。清理后留下的尸体、能量块属于资源，不计入存活总数。

### 调整温度、湿度、地形和种子

在第一页点击相应参数按钮，修改输入值或滑条，再点“应用”或按Shift提交。地形参数中的数值是 **陆地比例百分比**。

更新时会出现加载动画，完成后返回原世界和镜头，恢复原来的运行或暂停状态。温湿度修改只重算气候；地形和种子修改才重建地表。实体身份与游戏时间保留，地形变化后实体落点会适配新地表。

### 觉得卡顿时先看哪里

左上角显示FPS和平均帧耗时；发生模拟积压时，还会显示实际模拟倍率和待算时间。

先降到1倍，再观察数量和帧耗时。右键播放/暂停按钮可选择倍率。**选择16倍不代表机器一定完成16倍模拟**；大量个体、繁殖或复杂种群都会增加负担。先小规模熟悉功能，再逐步增加数量，不要依靠无限生成测试完整生态。

## 6. 进阶：观察蚁群

拥有种群基因且处于蚁群状态时，会形成王后和分工。活动后面的括号表示角色，例如“巡逻（士兵）”“运输（工匠）”。

| 角色 | 主要作用 |
| --- | --- |
| 王后 | 繁殖与维持种群，不能战斗，也不能被挑战替换 |
| 士兵 | 主动猎杀符合条件的外群目标，留下尸体，不直接吸收击杀营养 |
| 工匠 | 搬运尸体或不能移动的活体，转化为种群补给，不能正常战斗或繁殖 |
| 繁殖个体 | 成年后离群建立自己的种群 |
| 专用配偶 | 有性王后的繁殖伙伴，不进行独立繁殖 |

王后及幼体与成年成员使用不同的补给规则。看到黄色块却没有进食时，先确认角色、补给类型、距离和营养容量。

第一页的“种群”图层可观察不同种群的范围。同群识别影响攻击判断；普通领地巡逻有休息，只在真实受击后反击，蚁群士兵则可主动猎杀外群目标。

更详细的流程见[蚁群与巡逻](蚁群与巡逻说明.md)。

## 7. 进阶：用RTS指挥实体

1. 在星球视角按 **R** 进入RTS。
2. 左键拖出方框选择实体，按住Shift追加选择。
3. 右键地面下达移动指令；右键可攻击目标时会按条件攻击。
4. 使用权能栏上方的命令条选择攻击、采集、守卫或停止，具体操作取决于所选实体的实际基因和角色。
5. 再按R退出。RTS中用 **中键拖动**旋转镜头。

无有效行动能力的实体不会因为收到命令就能移动，工匠和王后也不会因此获得攻击能力。RTS中的右键用于下令；想按普通方式右键查看属性，先退出RTS。

单人管理员可以指挥符合权限的实体。联机普通成员操控王后时，只能指挥自己的种群，不能夺取其他玩家正在操控的实体。

## 8. 与朋友进行局域网游戏

**房主：**先进入单人世界，按Esc，选择“对局域网开放”，设置端口和作弊开关，再点击“开始开放”。把菜单显示的局域网IP和端口告诉成员；默认端口为 **47777**。

**成员：**主界面选择“多人游戏”，填写房主IP、相同端口和自己的名称，加入后选择尚未被占用的实体。

| 身份 | 可用能力 |
| --- | --- |
| 房主／唯一管理员 | 管理世界、基因、投放、上限、清除、模拟时间与房间设置 |
| 普通成员 | 选择实体游玩和查看信息；不能编辑基因、投放、修改上限或清除；操控王后时可指挥本群 |
| 开启作弊的成员 | 获得世界编辑能力，但不能自行开关作弊或关闭房间 |

普通成员只能在进入游戏或自身实体死亡后重新选择；作弊开关不会增加第二名管理员。联机中某个玩家打开Esc菜单不会暂停全体，世界由房主统一保存。

详细步骤见[局域网与RTS](局域网与RTS.md)。

## 9. 常见问题速查

| 遇到的情况 | 先检查什么 |
| --- | --- |
| 实体不动 | 是否暂停；是否有生效的移动能力；是否在水中、孵化、被搬运或受其他状态限制 |
| 能动但没有攻击 | 食性、是否需要进食、感知和距离、目标体型、同群关系，以及角色是否允许攻击 |
| 有基因却没效果 | 看“生效／失效”、表达属性和悬停提示；检查环境及其他基因的抑制 |
| 成年后仍不繁殖 | 储存营养、配偶、孕育/休养时间、角色限制和实体上限 |
| 黄色能量块就在旁边仍不吃 | 普通个体检查营养利用基因；蚁群检查补给类型、角色、距离和是否已满仓 |
| 深色球体无法当活体操控 | 看叉号及右键信息，可能是已死亡的尸体资源 |
| 右键只下令、不打开面板 | 先按R退出RTS；若正在投放，先取消投放 |
| 放不出更多实体 | 是否达到本存档上限、是否有管理权限、是否正在更新世界或点击在UI上 |
| 按键没有反应 | 是否在输入框中、菜单是否打开、是否暂停，以及联机权限是否允许 |
| 统计与眼前数量不同 | 统计包含全地图存活个体，排除尸体等资源；基因“携带”和“生效”也是不同口径 |

### 需要反馈问题时

在设置中点击 **打开日志文件夹**，保留对应时间的日志；同时记下发生步骤、世界名称、实体数量和模拟倍率，附上截图。联机问题由房主与成员分别保留日志。

存档默认位于游戏目录的`save/<世界标识>/world.json`，备份世界时复制整个对应文件夹。更多说明见[运行日志与测试](运行日志与测试.md)。

## 10. 最常用的按键

| 场景 | 常用操作 |
| --- | --- |
| 星球观察 | 左键拖动旋转，滚轮缩放，右键查看属性 |
| 时间控制 | P启停；星球视角也可用空格启停；右键底栏播放按钮选择倍率 |
| 实体操控 | 双击进入，WASD移动，鼠标转向，左键攻击，空格跳跃 |
| 鼠标与视角 | 按住Alt释放鼠标，Tab返回星球视角，Esc打开菜单 |
| 能量 | Q消耗营养吐出能量块，须满足基因与营养条件 |
| RTS | R切换，左键框选，Shift追加，中键转动，右键下令 |
| 放置／参数 | 右键或Esc取消放置；Shift应用参数草稿 |

以上快捷键在输入框、覆盖菜单或权限不满足时可能被屏蔽。先完成第一局的六个步骤，再按需要阅读[项目文档目录](../README.md)中的专题指南。
