# 蚁群与巡逻

普通领地个体按巡逻窗口和休息间隔活动，只在遭到攻击后反击可对抗的攻击者；发现附近有捕猎者不会主动开战。不能对抗时仍会逃离并重新定居。蚁群士兵可主动猎杀符合体型、感知条件并处于王后种群范围内的外群实体。

## 出生与分工

种群基因处于蚁群状态时，首个成员成为王后，其后出生个体获得固定分工。默认随机权重为士兵 35、工匠 60、繁殖个体 5；繁殖个体最多 2 名，种群达到 6 名且没有繁殖个体时优先补充 1 名。卵在孵化期间保留身份和分工。

| 分工 | 行为与限制 |
| --- | --- |
| 士兵 | 繁殖与营养基因受抑，遗传基因锁定。击败外群实体后留下可运输尸体，不获得攻击营养奖励；随后围绕王后沿圆形路径巡逻，并在巡逻窗口之间休息。空闲饥饿时前往共享补给。 |
| 工匠 | 繁殖受抑、遗传基因锁定、战斗属性为零。独占领取尸体或无法移动的外群实体，搬到王后区或群内随机补给点并转换为能量块。 |
| 繁殖个体 | 幼年跟随王后，成年后成为王后，带着新的种群身份离开原种群范围建群。 |
| 王后 | 无攻击能力，平时移速降低；有足够储备和有效繁殖基因时持续孕育，完成后自动准备下一轮。 |
| 专用配偶 | 有性王后单独产生并维持 1 名，不能自主繁殖；靠近王后参与繁殖，饥饿时可到成年补给点取食。 |

## 尸体、补给与种群显示

所有实体自然死亡、环境死亡或被击败后，未被消化吸收的营养都会形成尸体；完全吸收时没有空尸体。工匠可领取中立尸体、本群尸体或灭绝种群遗留尸体；仍存活外群的专属尸体受归属保护。多名工匠不能重复领取，同一具尸体被领取后食腐实体不会抢食，运达后按剩余营养转化为能量块。

工匠优先保证育幼区和成年补给均存在，其后默认以各 50% 的概率分配运输目的地。王后区的黄色发光能量块供王后和幼体吸收，其他成年成员只吸收同群补给点的能量。能量从被运输实体转换而来，运输与取食不会重复结算。

饥饿成员优先前往可用补给，工匠会保留货物并在吃饱后继续运输。旧种群已经没有任何存活成员时，其附近遗留能量块可由其他蚁群回收；实际进食后归入新群。仍有存活成员的种群继续保有补给。幼体先到育幼补给时，会给饥饿王后保留达到进食阈值所缺的口粮。

新增的操控栏、免费添加补给按钮与 E 补给已取消。双击操控后，P 启动/暂停，按住 Alt 释放鼠标、松开恢复操控；空格保持跳跃，Tab 返回星球。

“营养利用基因”是储存基因的出错分支，在基因树中以菱形显示；不再由营养方式基因正常演化产生。该基因生效且实体有足够营养时，操控中按 Q 在前方吐出通用能量块：优先扣除储存营养，不足部分扣饱食度，生成与扣除严格等量。基因值 50 时默认每块 5 能量，数值由基因属性曲线决定。无基因、失效、受抑或营养不足均不能吐出；暂停、按住 Alt、输入框和覆盖菜单期间 Q 无效。

蚁群原有自动吸收保留，各分工也能吸收通用块。非蚁群实体拥有有效营养利用基因后，饥饿时会主动靠近并吸收附近通用块或无主的旧群补给；不会抢食存活蚁群的专用口粮。吐出的通用块与独立基因都随世界存档保存。

实体的种群色环与持久种群标识对应；同群成员不能相互攻击。底部图层区的“种群”按钮显示不同种群的球面范围，再次点击关闭。实体面板可查看分工、当前任务与成员数量。

世界存档保存出生分工、固定基因快照、巡逻与休息计时、孕育进度、配偶遗传快照、补给点、尸体和运输关系；先恢复所有实体，再解析跨实体引用。旧世界缺少这些字段时按当前配置初始化。

## 调整参数

内置配置为 `Assets/Resources/Entities/ant_colony.json`，可复制为 `mods/Default/ant_colony.json` 供新世界使用。世界保存自身配置快照，已有世界继续使用自身规则。

- `patrolDuration`、`patrolRestMin`、`patrolRestMax`：普通巡逻窗口与休息区间，默认 4 秒和 12～20 秒。
- `patrolRetaliationOnly`：普通领地个体只受击反击，默认开启。
- `soldierPatrolSeconds`、`soldierRestSeconds`：士兵巡逻与休息窗口，默认 8 秒与 10 秒。
- `roles`：出生权重、基因抑制、攻击与移动倍率，以及遗传基因锁定。
- `minimumReproductives`、`maximumReproductives`、`reproductivePopulationThreshold`：繁殖个体数量控制。
- `supplyPointCount`、`nurseryDeliveryFraction`：群内随机补给点数量与育幼运输比例。
- `queenGestationSeconds`、`queenBirthCost`、`mateCost`：王后孕育时间、生产储备与产生配偶的开销。

所有时间均为模拟秒，随暂停和时间倍率推进。

营养利用的搜索/吸收半径、吐出距离及属性标识见 `Assets/Resources/Entities/nutrient_utilization.json`，可用 `mods/Default/nutrient_utilization.json` 覆盖；每块能量和吸收速率由 `gene_nutrient_utilization.json` 中的独立曲线配置。
