# 按键控制与游戏数值

在主菜单或游戏内Esc菜单打开设置，左侧选择“按键控制”。点击当前按键后，按新的键盘或鼠标按键；Esc取消这次等待。改键立即生效并保存到本机偏好，下次启动继续使用。冲突会提示已有用途，恢复默认会一次重置全部绑定。Esc保留给菜单，星球视角暂停和实体跳跃允许共用空格，因为两者不同时生效。

支持前后左右、跳跃、攻击、按住释放鼠标、退出实体操控、吐出能量块、暂停/继续、星球视角暂停和RTS切换。移动与攻击仍要求有效行动基因；改键不会绕过基因、体型、种群或联机权限检查。鼠标移动继续控制视线，双击实体进入操控和RTS选择/指令继续使用原鼠标操作。

## 修改游戏数值

编辑游戏目录的 `config/gameplay.json`，保存后重启。编辑器中对应工程根目录的同名文件，Windows游戏中对应可执行文件旁的 `config` 文件夹。首次运行缺少文件时自动生成；文件无法写入或内容无效时，日志会报告原因并使用内置默认值。不要改 `version`，JSON中不能加入注释。

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| `baseMetabolismMultiplier` | 1 | 基础饱食消耗倍率；0关闭基础消耗 |
| `movementMetabolismMultiplier` | 1 | 行动饱食消耗倍率；0.5减半，2翻倍，0关闭行动消耗 |
| `repairFoodPerHealth` | 0.5 | 每恢复1生命值消耗的饱食度 |
| `starvationDamagePerSecond` | 1 | 饱食耗尽后每模拟秒生命损失 |
| `manualAimPadding` | 0.85 | 手动攻击选择框各方向额外扩大距离 |
| `manualHitboxScale` | 1.5 | 手动攻击选择框相对真实碰撞框的倍率，至少1 |
| `manualAttackReachBonus` | 0.35 | 手动近战距离额外容差；AI沿用原距离 |
| `supplyActivityRadiusRatio` | 1 | 补给点活动圆相对王后圆的半径倍率，必须大于0 |

消耗公式是：`基础代谢 × 世界基础倍率 × 全局基础倍率 + 行动代谢 × 世界行动倍率 × 实际切向速度 × 全局行动倍率`，再乘实际交付的模拟秒数。移动速度按模拟倍率换算，不使用显示帧率；暂停不推进饱食结算。其余数值必须为非负有限数字。

这份配置是启动时读取的全局设置，同时作用于新世界和已有存档。原世界的基因、蚁群和生态平衡快照继续保存自己的规则，全局倍率作用于最终结算。联机时生命及饱食结算由房主负责，房主应修改自己的配置。分发构建时可附带此文件；不附带时游戏首次启动会生成。

## 攻击与种群范围

攻击判定扩大的是选择框，实体的物理体积保持原样。目标必须在准星前方，并通过真实视线遮挡检查；墙体和地形仍会阻挡，选中后还要满足实际近战距离。

蚁群活动区是王后圆、已配置补给存放点圆及实际专属补给圆的并集。种群范围图层绘制相同的圆，士兵巡猎及工匠的新采集任务也使用该范围。调整补给半径倍率后重启即可改变其范围；存放点位置沿用原存档记录。
