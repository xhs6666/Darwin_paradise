# 营养、尸体与寄生

更新日期：2026-11-01。

营养方式下新增“异养基因”，含“寄生”和“消化”两种状态；异养的出错分支为“食腐基因”。原来的寄生基因改名为“卵寄生基因”，仍属于卵生的出错分支。

| 基因/状态 | 作用 |
| --- | --- |
| 异养：寄生（默认中心值25） | 幼年靠近更大的宿主后附着，隐藏自身模型和碰撞，只能跟随宿主移动；持续吸取宿主饱食度，保留安全口粮，不直接扣宿主生命值。成年后脱离，恢复正常显示和行动，独立消化取食。 |
| 异养：消化（默认中心值75） | 击败活体后，根据消化效率和自身剩余容量吸收营养；吃不下或未消化的部分留下尸体。非致死攻击不提供食物。 |
| 食腐（默认中心值50） | 吸收尸体剩余营养。有行动能力时会寻找附近尸体；无行动能力时只能吸收接触范围内的尸体。不会抢食已被工匠领取的尸体。 |
| 卵寄生 | 将亲本构造的后代卵放入附近宿主，宿主获得独立的卵寄生孕育状态。卵的后代基因与宿主无关，成熟后孵化为独立实体。 |

宿主状态后会显示“（被寄生）”或“（卵寄生孕育 数量）”。两种机制可同时存在，互不借用宿主自身的怀孕标记。成年、宿主死亡或寄生基因失效会解除营养寄生；宿主死亡时尚未孵化的外来卵也结束。

行动基因提供移动和攻击能力，异养决定如何获得食物。有消化食性时，“食草”倾向只主动捕食静止实体，“捕猎”倾向可以追击移动实体。寄生幼体寻找宿主，食腐寻找尸体；没有行动能力不会获得额外移动能力。手动攻击、反击和士兵工作仍遵守体型、分工和同群保护规则。

自养与有效异养/食腐不会同时生产营养；若复制基因使食腐与异养共存，优先使用食腐食性。营养利用基因仍独立负责通用能量块的吸收和吐出。

所有实体寿终、饥饿、环境伤害或战斗死亡后，未被吸收的营养都会留下尸体。尸体可右键查看。工匠会独占领取中立、本群或灭绝种群遗留尸体，并按剩余营养搬运、转换为种群能量块；完全吸收后没有空尸体。清场和读档替换不会额外产生尸体。

基因树会为旧世界增量补齐这两条营养分支。营养寄生、卵寄生载荷和尸体资源都随世界保存，读档不混入宿主基因。营养寄生的默认安全饱食度为4，具体参数见 `Assets/Resources/Genetics/nutrition_ecology.json`。
