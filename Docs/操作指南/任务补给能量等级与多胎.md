# 任务、补给、能量等级与多胎

## 补给不再来回折返

工匠、士兵等成员饥饿时先执行补给计划，吃到恢复线后继续原运输/巡逻；途中保留货物。默认恢复线为饱食度 **9.5**，王后额外准备 **10** 点繁殖储备。供给目标在本次计划内固定，目标不可用时自动更换。

默认基础、移动、环境及孕育持续饱食消耗放慢；生产、猎食消化、寄生吸收、食腐和能量块吸收获取倍率设为 **0.5**。繁殖的单次储备成本与运输转换的实际能量不凭空减半。消化得少时，未吸收的部分仍留作尸体。

## 五级能量块

| 等级 | 颜色 | 实际剩余能量 |
|---|---|---|
| 1 | 蓝 | 大于0且小于20 |
| 2 | 绿 | 20～不足60 |
| 3 | 黄 | 60～不足180 |
| 4 | 橙 | 180～不足540 |
| 5 | 红 | 540及以上 |

补给堆合并后按总量变色，吸收后可以降级；颜色表示当前库存，改变颜色不会增加实际营养。

## 多胎基因

繁殖基因新增出错分支“多胎”。仍区分有性与无性；有效表达越高胎数越多，默认上限5。多胎需要相应繁殖储备，有性仍需合适配偶。数量达到上限或出生位置拥挤时保留未出生胎数，读档后继续，不重复生产已出生后代。王后同样支持。

## 外部调整

游戏目录的 `config/gameplay.json` 支持中文注释，保存后约2秒载入；无效值告警并继续使用有效配置。关键项：

| 配置 | 默认 | 用途 |
|---|---:|---|
| baseMetabolismMultiplier | 0.5 | 基础和持续环境/孕育消耗倍率 |
| movementMetabolismMultiplier | 0.5 | 实际行动消耗倍率 |
| nutritionGainMultiplier | 0.5 | 获取速度/消化预算倍率 |
| memberFeedResume | 9.5 | 补给完成饱食线 |
| queenReserveBuffer | 10 | 王后繁殖储备缓冲 |
| mergeStationaryEntities | true | 开启相近静止实体合并计算 |
| mergeRadius | 6 | 与代表的最大空间距离 |
| mergeInterval | 0.5 | 共享结算间隔（模拟秒） |
| mergeQuietSeconds | 2 | 安静多久进入低频计算 |
| mergeMaximumMembers | 32 | 每组最多成员 |
| mergeGroupsPerFrame | 128 | 每帧最多共享组 |
| mergeFoodTolerance / mergeReserveTolerance | 0.25 / 2 | 兼容营养区间，越小越精确 |
| mutationAttemptsPerFrame | 16 | 全局每帧自然阶段抽签预算 |
| mergedMutationFraction | 0.125 | 同组约有多少成员参与变异抽签 |
| multipleBirthMaximum | 5 | 新受孕的最大胎数 |

合并只针对健康、相近、同基因且状态兼容的静止实体。成长、寿命、营养和繁殖继续；受伤、移动、被搬运或基因改变时恢复单独处理。有限矿产、实际猎食、运输等保留独立计算。每个实体和孩子仍是独立身份。

`config/energy_levels.json` 可修改五级阈值、颜色和大小，支持注释，重启后应用。阈值必须递增、最低从0开始。更多维护说明见 [实体任务与近邻合并计算](../开发设计/实体任务与近邻合并计算.md)。

## 小种群繁衍优先

启用原有建群保障时，首批工匠到位、成员达到 `colonySuccessorPopulation`（默认3）后，优先出生繁殖个体，成年后迁出建立新群。后台比例补充和普通繁殖会给王后留 `colonyBirthReservedSlots`（默认2）个真实空位；不突破世界上限，不删除实体，也不限制玩家手动投放。没有成年王后时不保留名额，配置设0可关闭保留。旧世界若关闭建群保障，保留原有分工策略。

预算延期后轮到该组会补算累计时间；`mergeMaximumCatchupSeconds` 默认5秒，限制单次补算工作量，余量继续保存。欠算时间处在不同区间的实体分开调度，避免大量组在高倍率下永久落后。
