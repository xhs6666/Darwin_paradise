## 营养尸体与寄生

原文档：`Docs/操作指南/营养尸体与寄生.md`

<a id="doc-27b0e477aaa1-营养尸体与寄生"></a>

### 营养、尸体与寄生

更新日期：2026-11-01。

营养方式下新增“异养基因”，含“寄生”和“消化”两种状态；异养的出错分支为“食腐基因”。原来的寄生基因改名为“卵寄生基因”，仍属于卵生的出错分支。

| 基因/状态 | 作用 |
| --- | --- |
| 异养：寄生（默认中心值25） | 幼年靠近更大的宿主后附着，隐藏自身模型和碰撞，只能跟随宿主移动；持续吸取宿主饱食度，保留安全口粮，不直接扣宿主生命值。成年后脱离，恢复正常显示和行动，独立消化取食。 |
| 异养：消化（默认中心值75） | 击败活体后，根据消化效率和自身剩余容量吸收营养；吃不下或未消化的部分留下尸体。非致死攻击不提供食物。 |
| 食腐（默认中心值50） | 吸收尸体剩余营养。有行动能力时会寻找附近尸体；无行动能力时只能吸收接触范围内的尸体。不会抢食已被工匠领取的尸体。 |
| 卵寄生 | 将亲本构造的后代卵放入附近宿主，宿主获得独立的卵寄生孕育状态。卵的后代基因与宿主无关，成熟后孵化为独立实体。 |

宿主状态后会显示“（被寄生）”或“（卵寄生孕育 数量）”。两种机制可同时存在，互不借用宿主自身的怀孕标记。成年、宿主死亡或寄生基因失效会解除营养寄生；宿主死亡时尚未孵化的外来卵也结束。

行动基因提供移动和攻击能力，异养决定如何获得食物。有消化食性时，“食草”倾向只主动捕食静止实体，“捕猎”倾向可以追击移动实体。寄生幼体寻找宿主，食腐寻找尸体；没有行动能力不会获得额外移动能力。手动攻击、反击和士兵工作仍遵守体型、分工和同群保护规则。

自养与有效异养/食腐不会同时生产营养；若复制基因使食腐与异养共存，优先使用食腐食性。营养利用基因仍独立负责通用能量块的吸收和吐出。

所有实体寿终、饥饿、环境伤害或战斗死亡后，未被吸收的营养都会留下尸体。尸体可右键查看。工匠会独占领取中立、本群或灭绝种群遗留尸体，并按剩余营养搬运、转换为种群能量块；完全吸收后没有空尸体。清场和读档替换不会额外产生尸体。

基因树会为旧世界增量补齐这两条营养分支。营养寄生、卵寄生载荷和尸体资源都随世界保存，读档不混入宿主基因。营养寄生的默认安全饱食度为4，具体参数见 `Assets/Resources/Genetics/nutrition_ecology.json`。

FPS显示默认使用18%不透明度的背景，保留清晰文字；组件的 `backgroundOpacity` 设为0时完全透明。组合筛选、统计和随机生成下拉菜单使用统一主题滚动条，并移除无精灵时的默认勾选色块。

## 生态默认与建群保障

原文档：`Docs/操作指南/生态默认与建群保障.md`

<a id="doc-3c0d101a4d88-生态默认与建群保障"></a>

### 生态默认与建群保障

新世界默认记录生产者70%、移动实体30%的比例目标；旧补员基线数量字段仅用于存档兼容，不再保证或持续自动补充实体；新世界的一次性10个种源见[自然繁衍与陆地水系](生态与种群.md#doc-60f8a199cd72)。比例调节总规则默认关闭，需使用时在底栏第一页“规则控制 → 种群比例调节”打开并应用保存；开启后仅延缓超额类别的新繁殖，不足时依靠自然繁殖，不直接生成。世界实体上限继续生效。规则调节保留正在进行的实体操控和放置预览。

<a id="doc-3c0d101a4d88-已有世界怎么使用"></a>

#### 已有世界怎么使用

打开底部第二页的随机生成窗口，进入“维持比例规则”，点击“应用生态默认项”。两条默认规则会整体校验后应用，已有其他自定义规则保留；比例或规则上限冲突会显示未应用，不做部分修改。可以单独改比例、停用或删除规则。

旧世界加载时沿用原规则列表，建群保障按配置生效。已经灭绝的种群保留原档案记录；手动投放可用于建立新的生态，不改写过去的历史。

<a id="doc-3c0d101a4d88-默认模板"></a>

#### 默认模板

生成来源页和比例规则页都提供这些基础模板：

|模板|用途|
|---|---|
|默认生产者 · 自养繁衍|静止阳光自养，带成长、无性繁殖、储粮、修复和环境适应。|
|自然先驱 · 自养行动|一次性自然种源使用的移动自养模板。|
|默认移动实体 · 消化取食|带行动、消化异养、无性繁殖、储粮、修复、环境适应及能量块利用。|
|蚁群创始王后 · 无性繁殖|具备种群、行动、繁殖和储粮等建群所需基因，可用于手动投放新蚁群。|
|移动清道夫 · 食腐回收|带食腐、行动、无性繁殖、储粮和能量块利用，供手动选择。|

前两个模板对应启用的70/30规则。王后与清道夫作为额外生成来源列出，用户可按需投放或自行配置规则。

默认生态规则按实体实际表达能力统计：生产者沿用游戏“静止自养”的判定；移动者按有效移动能力判定。王后、工匠和发生其他基因变异的实体也能正确归类。两类共享“生产者＋移动者”的分母；没有产能、也不能移动的特殊个体单独保留，不让这两条100%分区反复补充。普通的模板/必有必无规则仍按原来的来源条件统计。

<a id="doc-3c0d101a4d88-新王后怎样建立补给链"></a>

#### 新王后怎样建立补给链

- 定居的新王后在小型建群阶段默认领取一次64点育幼储粮。领取标志、已发数量和运输状态随实体存档保存，重新载入和基因重算不重复领取。
- 缺工匠时，王后优先繁殖工匠，直到群内有2名工匠；仍支付原有繁殖食物和孕育时间。这个阶段优先建立补给链，免于全局移动者比例超量造成的繁殖等待。
- 工匠成年前，王后临时执行原有采集、搬运和送达流程。2名成年工匠到位后，王后送完手中货物，再恢复专职繁殖。
- 原自动补充不足类别的行为已停用，已有局部补充数量配置仅保留旧档兼容；种源可通过手动投放建立。

创业储粮是有限初始物资。寿命、饥饿、攻击、环境适应和实体上限都继续生效；长期延续仍依赖生产、采集、繁殖与正常遗传。

<a id="doc-3c0d101a4d88-外部配置"></a>

#### 外部配置

编辑游戏目录的`config/ecology_defaults.json`。仓库提供该文件；发布版缺失时从内置默认复制生成。支持中文行注释、块注释和UTF-8文本。

|参数|默认值|作用|
|---|---:|---|
|enableNewWorldRules|true|新世界记录默认比例；全局调节总开关仍默认关闭。|
|minimumPopulation|10|旧比例规则参考基数，不触发持续补员。|
|producerRatio / mobileRatio|0.7 / 0.3|两个比例之和需为1。|
|enableFoundingSupport|true|启用有限创业补给、工匠优先及王后临时采集。|
|minimumWorkers|2|建群优先补齐的工匠数量。|
|foundingFood|64|新王后的一次性育幼储粮。|
|maximumFoundingMembers|4|只对尚处小型起步阶段的种群发放初始储粮。|
|localProducerTarget|8|旧局部补充兼容字段，当前不触发生成。|
|plantSpacing|3|优先投放时避开现有实体的间距。|
|templates|五种模板|各模板的完整基因、数值与阶级。|

新世界使用修改后的文件。已有世界保存自己的生态配置快照；在维持比例页显式点击“应用生态默认项”会重新读取外部配置并应用。联机时由房主校验、生成和推进，客户端接收规则及低频配置同步。

相关文件：`EcologyDefaults.cs`负责默认项与配置，`EcologyMaintenancePolicy.cs`负责分类及投放偏好，`ColonyFoundingSupport.cs`负责建群交接，原采集、繁殖和地形生成入口继续承担实际执行。

## 蚁群与巡逻说明

原文档：`Docs/操作指南/蚁群与巡逻说明.md`

<a id="doc-26dabc11f2af-蚁群与巡逻"></a>

### 蚁群与巡逻

普通领地个体按巡逻窗口和休息间隔活动，只在遭到攻击后反击可对抗的攻击者；发现附近有捕猎者不会主动开战。不能对抗时仍会逃离并重新定居。蚁群士兵可主动猎杀符合体型、感知条件并处于种群活动范围内的外群实体。

种群活动范围是以王后和实际存有剩余能量的补给位置为中心的球面圆的并集。全局 `colonyActivityRadiusMultiplier` 默认0.35，通常初始王后圆从45缩为15.75；补给圆再乘 `supplyActivityRadiusRatio`。王后出生不预建空检查点，货物运达并转化为实际能量后才扩展范围，能量耗尽后取消扩展；旧档的空存放位置不再产生范围。默认半透明填色，右键种群图层按钮切换合并外轮廓，两种模式都不保留内部交叉边框。图层、士兵捕猎/巡逻、领地防御和工匠新采集目标共用这些范围；感知距离仍单独生效。正在运输的货物会继续送达。狼群沿用领袖活动圆。

<a id="doc-26dabc11f2af-出生与分工"></a>

#### 出生与分工

种群基因处于蚁群状态时，首个成员成为王后，其后出生个体获得固定分工。默认随机权重为士兵 35、工匠 60、繁殖个体 5；繁殖个体最多 2 名，种群达到 6 名且没有繁殖个体时优先补充 1 名。卵在孵化期间保留身份和分工。

| 分工 | 行为与限制 |
| --- | --- |
| 士兵 | 繁殖与营养基因受抑，遗传基因锁定。击败外群实体后留下可运输尸体，不获得攻击营养奖励；随后围绕王后沿圆形路径巡逻，并在巡逻窗口之间休息。空闲饥饿时前往共享补给。 |
| 工匠 | 繁殖受抑、遗传基因锁定、战斗属性为零。独占领取尸体或无法移动的外群实体，搬到王后区或群内随机补给点并转换为能量块。 |
| 繁殖个体 | 幼年跟随王后，成年后成为王后，带着新的种群身份离开原种群范围建群。 |
| 王后 | 无攻击能力，平时移速降低；有足够储备和有效繁殖基因时持续孕育，完成后自动准备下一轮。 |
| 专用配偶 | 有性王后单独产生并维持 1 名，不能自主繁殖；靠近王后参与繁殖，饥饿时可到成年补给点取食。 |

<a id="doc-26dabc11f2af-尸体补给与种群显示"></a>

#### 尸体、补给与种群显示

所有实体自然死亡、环境死亡或被击败后，未被消化吸收的营养都会形成尸体；完全吸收时没有空尸体。工匠可领取中立尸体、本群尸体或灭绝种群遗留尸体；仍存活外群的专属尸体受归属保护。多名工匠不能重复领取，同一具尸体被领取后食腐实体不会抢食，运达后按剩余营养转化为能量块。

工匠优先保证育幼区和成年补给均存在，其后默认以各 50% 的概率分配运输目的地。王后和幼体优先吸收育幼块，其他成年成员优先成年补给点；默认允许在缺少专用补给或身边已有可用块时跨用途进食，通用块均可使用。能量从被运输实体转换而来，运输与取食不会重复结算。

饥饿成员优先前往可用补给，工匠会保留货物并在吃饱后继续运输。旧种群已经没有任何存活成员时，其附近遗留能量块可由其他蚁群回收；实际进食后归入新群。仍有存活成员的种群继续保有补给。幼体或借用育幼块的成年成员先到时，会给饥饿王后保留达到进食阈值所缺的口粮。身边的可用能量块不会因远处任务锁定而被忽略，新王后迁居也会先补给后继续。

新增的操控栏、免费添加补给按钮与 E 补给已取消。双击操控后，P 启动/暂停，按住 Alt 释放鼠标、松开恢复操控；空格保持跳跃，Tab 返回星球。

“营养利用基因”是储存基因的出错分支，在基因树中以菱形显示；不再由营养方式基因正常演化产生。该基因生效且实体有足够营养时，操控中按 Q 在前方吐出通用能量块：优先扣除储存营养，不足部分扣饱食度，生成与扣除严格等量。基因值 50 时默认每块 5 能量，数值由基因属性曲线决定。无基因、失效、受抑或营养不足均不能吐出；暂停、按住 Alt、输入框和覆盖菜单期间 Q 无效。

蚁群原有自动吸收保留，各分工也能吸收通用块。非蚁群实体拥有有效营养利用基因后，饥饿时会主动靠近并吸收附近通用块或无主的旧群补给；不会抢食存活蚁群的专用口粮。吐出的通用块与独立基因都随世界存档保存。

实体的种群色环与持久种群标识对应；同群成员不能相互攻击。底部图层区的“种群”按钮显示不同种群的球面范围，再次点击关闭。实体面板可查看分工、当前任务与成员数量。

世界存档保存出生分工、固定基因快照、巡逻与休息计时、孕育进度、配偶遗传快照、补给点、尸体和运输关系；先恢复所有实体，再解析跨实体引用。旧世界缺少这些字段时按当前配置初始化。

<a id="doc-26dabc11f2af-调整参数"></a>

#### 调整参数

内置配置为 `Assets/Resources/Entities/ant_colony.json`，可复制为 `mods/Default/ant_colony.json` 供新世界使用。世界保存自身配置快照，已有世界继续使用自身规则。

- `patrolDuration`、`patrolRestMin`、`patrolRestMax`：普通巡逻窗口与休息区间，默认 4 秒和 12～20 秒。
- `patrolRetaliationOnly`：普通领地个体只受击反击，默认开启。
- `soldierPatrolSeconds`、`soldierRestSeconds`：士兵巡逻与休息窗口，默认 8 秒与 10 秒。
- `roles`：出生权重、基因抑制、攻击与移动倍率，以及遗传基因锁定。
- `minimumReproductives`、`maximumReproductives`、`reproductivePopulationThreshold`：繁殖个体数量控制。
- `supplyPointCount`、`nurseryDeliveryFraction`：群内随机补给点数量与育幼运输比例。
- `queenGestationSeconds`、`queenBirthCost`、`mateCost`：王后孕育时间、生产储备与产生配偶的开销。

所有时间均为模拟秒，随暂停和时间倍率推进。

营养利用的搜索/吸收半径、吐出距离及属性标识见 `Assets/Resources/Entities/nutrient_utilization.json`，可用 `mods/Default/nutrient_utilization.json` 覆盖；每块能量和吸收速率由 `gene_nutrient_utilization.json` 中的独立曲线配置。

## 任务补给能量等级与多胎

原文档：`Docs/操作指南/任务补给能量等级与多胎.md`

<a id="doc-014b97b53594-任务补给能量等级与多胎"></a>

### 任务、补给、能量等级与多胎

<a id="doc-014b97b53594-补给不再来回折返"></a>

#### 补给不再来回折返

工匠、士兵等成员饥饿时先执行补给计划，吃到恢复线后继续原运输/巡逻；途中保留货物。默认恢复线为饱食度 **9.5**，王后额外准备 **10** 点繁殖储备。供给目标在本次计划内保持；目标不可用时自动更换，身边已经能吃到的能量块可直接用于补给。默认饱食低于3时可解除远处计划，改选最近可吃的块；未到危急线时保持有效计划。迁居中的新王后也先补给，吃饱后继续原建群目标。

默认基础、移动、环境及孕育持续饱食消耗放慢；生产、猎食消化、寄生吸收、食腐和能量块吸收获取倍率设为 **0.5**。繁殖的单次储备成本与运输转换的实际能量不凭空减半。消化得少时，未吸收的部分仍留作尸体。

王后和幼体优先育幼块，成年成员优先成年补给点，通用能量块均可使用。默认允许使用备用类别：缺少专用补给或身边已有其他可用块时，允许实际进食。借用育幼块仍为饥饿王后预留最低口粮；不能吸收仍有存活成员的外群专用补给。

<a id="doc-014b97b53594-五级能量块"></a>

#### 五级能量块

| 等级 | 颜色 | 实际剩余能量 |
|---|---|---|
| 1 | 蓝 | 大于0且小于20 |
| 2 | 绿 | 20～不足60 |
| 3 | 黄 | 60～不足180 |
| 4 | 橙 | 180～不足540 |
| 5 | 红 | 540及以上 |

补给堆合并后按总量变色，吸收后可以降级；颜色表示当前库存，改变颜色不会增加实际营养。

<a id="doc-014b97b53594-多胎基因"></a>

#### 多胎基因

繁殖基因新增出错分支“多胎”。仍区分有性与无性；有效表达越高胎数越多，默认上限5。多胎需要相应繁殖储备，有性仍需合适配偶。数量达到上限或出生位置拥挤时保留未出生胎数，读档后继续，不重复生产已出生后代。王后同样支持。

<a id="doc-014b97b53594-外部调整"></a>

#### 外部调整

游戏目录的 `config/gameplay.json` 支持中文注释，保存后约2秒载入；无效值告警并继续使用有效配置。关键项：

| 配置 | 默认 | 用途 |
|---|---:|---|
| baseMetabolismMultiplier | 0.5 | 基础和持续环境/孕育消耗倍率 |
| movementMetabolismMultiplier | 0.5 | 实际行动消耗倍率 |
| nutritionGainMultiplier | 0.5 | 获取速度/消化预算倍率 |
| memberFeedResume | 9.5 | 补给完成饱食线 |
| queenReserveBuffer | 10 | 王后繁殖储备缓冲 |
| colonyShareBackupFood | true | 允许跨育幼/成年用途使用备用补给，false恢复严格分类 |
| colonyEmergencyFeedThreshold | 3 | 饱食低于此值可改选更近食物，0关闭紧急换目标 |
| mergeStationaryEntities | true | 开启相近静止实体合并计算 |
| mergeRadius | 6 | 与代表的最大空间距离 |
| mergeInterval | 0.5 | 共享结算间隔（模拟秒） |
| mergeQuietSeconds | 2 | 安静多久进入低频计算 |
| mergeMaximumMembers | 32 | 每组最多成员 |
| mergeGroupsPerFrame | 128 | 每帧最多共享组 |
| mergeFoodTolerance / mergeReserveTolerance | 0.25 / 2 | 兼容营养区间，越小越精确 |
| mutationAttemptsPerFrame | 16 | 全局每帧自然阶段抽签预算 |
| mergedMutationFraction | 0.125 | 同组约有多少成员参与变异抽签 |
| multipleBirthMaximum | 5 | 新受孕的最大胎数 |

`config/energy_levels.json` 可修改五级阈值、颜色和大小，支持注释，重启后应用。阈值必须递增、最低从0开始。更多维护说明见 [实体任务与近邻合并计算](../开发设计/性能与坐标.md#doc-b005bf979546)。

<a id="doc-014b97b53594-小种群繁衍优先"></a>

#### 小种群繁衍优先

启用原有建群保障时，首批工匠到位、成员达到 `colonySuccessorPopulation`（默认3）后，优先出生繁殖个体，成年后迁出建立新群。后台比例补充和普通繁殖会给王后留 `colonyBirthReservedSlots`（默认2）个真实空位；不突破世界上限，不删除实体，也不限制玩家手动投放。没有成年王后时不保留名额，配置设0可关闭保留。旧世界若关闭建群保障，保留原有分工策略。

预算延期后轮到该组会补算累计时间；`mergeMaximumCatchupSeconds` 默认5秒，限制单次补算工作量，余量继续保存。欠算时间处在不同区间的实体分开调度，避免大量组在高倍率下永久落后。

## 种群档案与发展谱系

原文档：`Docs/操作指南/种群档案与发展谱系.md`

<a id="doc-cf47514a7827-种群档案与发展谱系"></a>

### 种群档案与发展谱系

底栏第二页的“种群档案”提供“全部种群列表”和“显示配置”入口。第一页保留地图实体统计和实体筛选。普通联机成员也可在第二页查看档案，不需要创造权限。

<a id="doc-cf47514a7827-完整列表与详情"></a>

#### 完整列表与详情

左侧列出所有已记录种群，包含存活和已灭绝种群，支持按名称或编号搜索、状态筛选及分页。选择种群后，右侧可查看：

- **概览**：当前成员、历史峰值、成立或首次观察时间、累计成员增加和流失、来源与最近事件。成员增加/流失包括出生、死亡和迁移，不等同于纯出生/死亡统计。
- **基因**：携带人数、携带率、生效人数和生效率，可勾选只统计生效基因。重复携带同一基因的实体只计一次。扇形图按所有基因的携带/生效人次计算构成；每项图例另列该基因在群体内的携带/生效率，因此多个基因的携带率可同时为100%。柱状图显示人数。
- **年龄**：幼年、成年、老年人数与百分比，支持扇形图和柱状图；存活群体还显示平均寿命进度。
- **发展历史**：规模随模拟时间变化的图表、事件及采样明细。默认每10模拟秒记录一次，成员数变化会立即产生记录；暂停不重复制造相同历史点。
- **衍生种群**：显示由该种群发展出的新种群和后续世代，点击可跳到对应档案，也可返回来源种群。
- **成员**：分页浏览该种群全部当前存活成员，可定位具体实体。
- **显示设置**：红、绿、蓝滑条分别使用对应颜色，也可用`#RRGGBB`设置颜色、预览并保存；可单独隐藏种群范围和成员标记，也可恢复默认配色后保存。勾选“同步实体颜色”并保存后，该种群成员的身体外观使用种群配色；取消勾选并保存会恢复实体原色。此选项默认关闭，受击红色闪烁结束后恢复当前配色；新加入的成员同样适用。颜色、同步选项和显示状态随世界保存，联机由房主配置并同步。

打开档案时，单人模拟暂停，底层操作被屏蔽；关闭后恢复打开前的运行状态。联机中打开档案不暂停房间。Esc关闭窗口。

概览、事件、历史图表与采样明细的时间均显示为游戏内的“第 X 年 X 月 X 日”，与底栏日历一致；存档仍保留原始模拟时间。

“显示设置”中可用“范围不透明度”滑条选择0%～100%，点击“保存显示配置”后作用于该种群的范围填色和外沿。各群独立保存，不改变实体身体的透明度。尚未单独设置的种群沿用 `config/gameplay.json` 中的 `populationFillOpacity`；旧档缺少新字段同样沿用此默认值。

<a id="doc-cf47514a7827-来源和历史记录"></a>

#### 来源和历史记录

蚁群繁殖个体实际离群建群时记录来源；种群状态变化后独立成群、非蚁群后代在外独立成群时也会记录。加入已存在的群体不会修改该群的来源。谱系可跨多代查看，灭绝群体的档案和最后存活基因/年龄分布继续保留。

旧存档没有此前的档案数据，只从本版本首次观察开始记录，并明确显示“此前历史未记录”。不会按位置、名称或相似基因推测过去的成立时间和来源。

历史采样默认最多512条，超出时压缩中间点、保留最早和最新记录；事件默认保留最近256条。容量及记录间隔由 `Assets/Resources/Entities/population_archive.json` 配置。实际历史、谱系、显示配置保存在世界存档的 `colony.population` 中，加载前检查非法采样和循环来源关系。

## 随机生成与比例维持

原文档：`Docs/操作指南/随机生成与比例维持.md`

<a id="doc-3f7f0ae64c5a-随机生成与比例维持"></a>

### 随机生成与比例维持

底栏第二页的“随机生成 · 全星球”中，点击“选择实体”打开两列来源界面。两种生成方式互斥：

- **左列：实体模板**。选择默认实体或已保存模板，完全使用模板保存的基因和数值，不附加随机基因。模板副本拥有独立的基因实例。
- **右列：基因条件随机**。为任意基因点击主题按钮“一定有”或“一定没有”；同一基因的两种条件互斥。未限定的其他基因及其数值逐个实体随机生成。同批实体会不同，而非复制一次随机结果。

点击“应用生成来源”回到底栏，填写数量并点击“随机生成”。来源窗口中的陆地范围选择会同步到底栏。默认单批10个，上限200个；“取消本批”停止当前生成，不删除已经生成的实体。按明确来源生成的初始实体不会在出生当帧再重抽变异，成年后的自然变异继续生效。

<a id="doc-3f7f0ae64c5a-保存基因条件-json"></a>

#### 保存基因条件 JSON

右列的搜索框支持输入基因名称或编号，编号搜索不区分大小写。输入条件名称后点击“保存条件 JSON”，每个条件单独保存在游戏目录 `templates/spawn-conditions/<编号>.json`，文件为缩进排版的 UTF-8 JSON。上方“选择已保存的基因条件…”可重新使用。

可在游戏外修改 JSON 中的 `source.name`、`source.included`（必有基因编号列表）和 `source.excluded`（必无基因编号列表）；其他未指定基因仍随机。保留文件名与 `id` 一致、`version=1` 和 `source.method=1`。重新打开来源窗口会从磁盘读取。格式或基因编号无效时跳过该文件并记录警告，原文件保留。

条件文件属于本机跨世界的来源库；启用后的维持规则保存来源快照，外部修改条件不会悄悄改变已经运行的规则。保存条件本身不会自动开启维持。

<a id="doc-3f7f0ae64c5a-维持比例"></a>

#### 维持比例

点击“维持比例…”或来源窗口的“维持比例规则”，自动列出默认实体、所有实体模板、已保存的基因条件、当前未保存的基因条件及历史规则来源。每行显示模板或必有／必无基因说明、当前数量与占比；填写该行目标比例并点击“启用维持”即可使用。已有规则可保存比例、启停、查看来源或移除。移除规则保留来源 JSON。也可以在来源页底部添加当前来源的规则。默认最多保存8条规则。比例范围为0%到100%；不再直接补员后，100%目标也可保存。

底栏**第一页 → 规则控制 → 种群比例调节**提供独立总开关，默认关闭；点击“应用并保存”才生效。开关保存于房主本机 `config/gameplay.json` 的 `populationRatioControlEnabled`，同时作用于新旧世界。单条比例及来源仍随世界保存。旧自动补员入口已停用，开启新规则也不会直接生成实体。

总规则开启时，每条启用的比例规则分别执行：

- **少于目标**：等待自然繁殖恢复，不直接生成。需要投放时，使用原有手动随机生成按钮。
- **高于目标**：延长匹配实体开始下一次孕育前的等待，普通实体和蚁群王后都适用。正在进行的孕育继续完成，现有实体不会被删除；营养、配偶、冷却、年龄和分工限制仍保留。
- **完整互斥分区**：例如“有行动”33.3%和“无行动”66.7%，只抑制超额类别的新繁殖。互斥规则的目标总和超过100%会被拒绝。

总数采用全地图存活并启用的实体。基因条件按“携带”判断，禁用或受抑制的基因仍算存在；模板规则按保存的基因、数值、复制强度、开关和缺失状态匹配，不按名称或血缘统计。自然变异后可能不再匹配原来的规则。

关闭总开关后不调节繁殖比例，但保留所有来源和目标值。开启后仅延长超额类别的新孕育等待；仍遵守食物、年龄、配偶和世界总上限。空世界不会因为比例规则而被重新填满。

规则和繁殖等待随世界存档保存，切换世界时停止旧任务；旧档保存的维持规则只作为目标配置恢复，不再触发自动补员。清除全部实体会同时停用维持规则，避免立即重新生成。联机中由房主执行，管理员及开启作弊的成员可编辑，普通成员不能通过生成或规则编辑入口绕过权限。

<a id="doc-3f7f0ae64c5a-蚁群站位"></a>

#### 蚁群站位

休息和跟随成员分散在王后或补给点周围，进入进食半径即可进食，不再全部冲向中心身体。移动时进行同群切向避让；地面检测只识别真实星球碰撞体。王后新生后代及专用配偶优先选择育幼范围内的空位，空间不足时保留孕育等待，而非继续向头顶叠加实体。

默认队形间距、避让和出生尝试次数位于 `Assets/Resources/Entities/colony_formation.json`；随机附加基因数量、补充预算、轮询模拟间隔及超量繁殖等待位于 `Assets/Resources/Entities/population_maintenance.json`。这些是工程资源配置；实际来源、比例和开关通过游戏内界面调整并保存在各世界中。

## 自然繁衍与陆地水系

原文档：`Docs/操作指南/自然繁衍与陆地水系.md`

<a id="doc-60f8a199cd72-自然繁衍与陆地水系"></a>

### 自然繁衍与陆地水系

<a id="doc-60f8a199cd72-人口与时间"></a>

#### 人口与时间

新世界只在创建时建立10个陆地幼体种源：7个静止自养生产者、3个可行动的自养先驱。移动先驱同样能获取阳光营养，降低起步阶段没有猎物的断粮风险。读档、清场和灭绝后都不自动重建种源；已有存档保留人口和身份。手动随机生成继续按玩家请求执行。

新孕育默认限制为15～360游戏天，参考生产者180天、普通移动者270天、王后90天。已怀孕实体保留原来的剩余孕育时间；修改配置不重置进度。普通实体参考5年成年、35年老年、45年寿命，产后等待9年；工匠参考30天成年，王后产后等待180天。成长、衰老、孕育相关基因继续影响实际速度，工匠仍有角色约束。

10个参考个体、无环境死亡且营养充足的理想谱系投影约50.45年达到1000个体。这是数值标定，不是强制人口目标，也不是完整生态50年运行保证。配偶、营养、环境、死亡、基因变异及实体上限均会改变实际结果。

默认1游戏天=10模拟秒、365游戏天=1游戏年。1倍速、正常负载时约10现实秒经过1游戏天；暂停不推进，倍率越高现实等待越短，过载则更长。规则页周期按“游戏天”输入，JSON原有时间字段仍按模拟秒保存。

<a id="doc-60f8a199cd72-外部调整"></a>

#### 外部调整

游戏根目录 `config/natural_population.json` 支持中文注释。运行中约每2现实秒检查文件变化，错误配置会警告并保留上次有效值。发布版缺少文件时从内置资源复制生成。

|字段|默认|用途|
|---|---:|---|
|enabled|true|采用自然年限；关闭后使用旧生命周期速度。|
|initialPopulation|10|新世界一次性种源数量；旧世界不补员。|
|maturityYears / elderYears / lifespanYears|5 / 35 / 45|参考成年、老年和寿命。|
|minimumGestationDays / maximumGestationDays|15 / 360|新孕育天数上下限。|
|producerGestationDays / consumerGestationDays|180 / 270|参考孕育天数。|
|postpartumYears|9|普通实体产后间隔。|
|queenGestationDays / queenCooldownDays|90 / 180|王后孕育与产后间隔。|
|workerMaturityDays|30|工匠参考成年天数。|
|producerTemplate / mobileTemplate|producer / pioneer_mobile|一次性种源使用的模板。|

`config/ecology_defaults.json` 保留生产者70%、移动者30%的目标配置。全局“种群比例调节”默认关闭；打开后仅延缓超额类别开始新孕育，不足时也不会直接生成实体。`minimumPopulation` 和局部补充字段是旧规则兼容字段，不是持续补员开关。

当前定时变异默认仍为每3游戏天抽取10%。采用多年成年节奏时，幼体会经历更多轮抽选；可在规则页自行增加周期，或切换生命阶段模式。修改总规则影响本机房主的新旧世界。

#### 高原、盆地、河流和湖泊

新世界默认启用宽阔高原与盆地，汇水形成连通河网，盆地按溢流水位积水成湖。河湖有独立水面；实体落水判断使用当前位置的实际水位。雨林用较深青绿、热带草原用金黄，并增加针叶林、草原及寒冷荒漠分类。该模型近似赤道辐合、副热带干燥和中纬度降水，尚未模拟完整季风、季节和柯本气候分类。

旧档没有新地貌字段时保留原地形。在“地形”参数页点击“启用高原 / 河流 / 湖泊并重建”即可显式升级；也能关闭并重建。操作沿用后台更新流程，保存日期、实体身份和资源能量，完成后重新贴地。地貌变化会改变岸线和可行走范围，建议先保留存档备份。

详细地貌和寻路设置位于星球生成组件的 `landforms`、`navigation` 参数中，并随地形参数写入世界存档。

#### 陆地寻路

无游泳能力的AI按陆地连通区筛选猎物、尸体和远处能量块，跨海目标不入队。路线使用共享预算的A*绕湖或沿岸行走，路线待算时停步，移动前再次检查水面与坡度。手动操控仍保留玩家操作语义。

默认每帧最多展开512个节点且约1.5毫秒预算；请求共用工作数组和路线缓存。导航网格是近似地表，狭窄通道和很小岛屿可能没有合适节点，保守停步；高精度需求可调整网格与采样间距，同时会增加生成及搜索成本。
