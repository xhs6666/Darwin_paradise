# 权能栏统计与帧率

“地图实体统计”现在只显示在权能栏第一页参数按钮右侧。宽度260逻辑单位；管理员卡片高度164，含底部清理按钮，普通成员使用136高的只读卡片：

- **实体总数**：当前地图所有存活实体，包含镜头外的个体；排除生命归零、已移除或停用的实体。
- **年龄分布**：幼年、成年、老年数量。
- **基因筛选**：从当前世界的基因列表选择一个基因，显示携带该基因的实体数量、当前表达生效的实体数量，以及携带个体占全体的百分比。

同一实体即使有多个复制基因，也只计一个携带者。被禁用或抑制的基因可能仍被携带，但不计入生效数。选择“全部实体”返回总体信息。筛选只用于观察，普通联机成员也可以使用。

统计默认每 0.5 秒更新，出生、死亡、基因变化及联机同步后会随之更新；离开世界时归零。


## 组合筛选与实体列表

统计卡右侧新增“实体筛选”。空间不足时，点击统计标题旁的“筛选”按钮，在底栏上方展开条件。

1. 在“包含”下拉框选择一个或多个基因；实体必须携带全部所选基因。
2. 在“不包含”下拉框选择一个或多个基因；携带其中任意一个的实体都会排除。
3. 已选项会标注“已选”，再次选择可取消；“清空本组条件”只清除该组，“重置”清除全部条件。同一基因不能同时包含和排除，最后一次选择决定所属组。
4. 匹配数量显示为“匹配 N / 当前存活实体总数”。点击“查看实体列表”，可分页查看名称，点击实体定位镜头，右键查看其属性。

例如：包含“生长基因”，不包含“行动基因”，可找到携带生长基因但没有行动基因的个体。这里的“携带”包含被禁用、抑制或未生效的基因；不要把基因不生效当成没有基因。

列表默认每页最多10项，复用固定数量的行，少量结果时自动缩短。出生、死亡、基因增删后默认每0.5秒更新；实体刚死亡或移除时不会继续定位失效引用。切到第二页或离开世界会关闭列表。

组合条件与原统计卡的单基因“携带/生效”统计独立。组合筛选只查询和定位，普通联机成员也能使用；不会改变实体、开放编辑权限或改变“清除全部实体”的范围。筛选条件不写入存档。

按 R 进入 RTS 后，操作栏位于整条权能栏上边缘的外侧，跟随实际 Canvas 缩放，留有间距。点击命令或统计下拉菜单不会同时触发地面指令。

左上角显示 FPS 和平均帧耗时，每 0.5 秒刷新，使用真实帧时间。暂停、16 倍模拟或打开菜单时仍显示实际渲染帧率。原实体面板下移以留出 FPS 的空间。

机器承载不足时，FPS下方额外显示实际完成的模拟倍率和待算秒数。高倍率不会在一帧无限补算，暂停不会增加待算时间；恢复后渐进处理。显示的FPS来自渲染帧耗时，不能把选择16倍理解为机器始终完成16倍模拟。


右上角齿轮打开“本存档游戏设置”，可输入实体上限，保存立即写入当前世界。新世界及缺少该字段的旧档默认3000，0表示不限。上限同时限制投放、随机生成和繁殖；降低上限不删除已有个体，读档完整恢复已有实体。满额的完成孕育等待空位，不伪造后代。

全局设置通过主菜单或Esc菜单进入，左侧分页包含按键控制，可修改并保存操控按键。底栏不再显示先前误加的设置按钮；统计栏右上角仍是本存档实体上限设置。

底部“清除全部实体”一键清除整个地图的实体，并保存清除结果；当前基因筛选不缩小清除范围，同时取消未完成的随机生成任务。联机中普通成员仍能查看第一页统计，但看不到创造、设置或清除按钮；管理员及开启作弊的成员可操作，服务端再次验证权限。

修改温度、湿度、种子或地形时，复用加载进度动画，在原世界中后台计算，完成后恢复原镜头及原先的运行/暂停状态。温湿度只重算气候；种子和地形才重建地表。地形参数为陆地比例百分比，不再误写湿度。更新期间不能继续修改或投放，进度结束后恢复操作。

右键深色的尸体资源可打开只读属性，显示死亡状态、剩余营养及搬运状态；新尸体还记录生前名称和体型。尸体有暖色叉号标记，不计入存活实体总数。旧存档没有记录的来源属性会明确标为未记录。

种群档案入口位于第二页，打开完整列表可搜索存活/灭绝种群、查看基因和年龄图表、发展历史及衍生谱系，并单独配置显示颜色。第一页保留实体统计及筛选。种群范围默认半透明填色，按钮右键切换合并外轮廓；左键再次点击关闭且取消绿色高亮。L依次切换图层，反引号键取消显示，设置页可修改两项按键。
