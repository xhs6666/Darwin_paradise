## 新手入门指南

原文档：`Docs/操作指南/新手入门指南.md`

<a id="doc-53e49d4d3f01-达尔文乐园新手入门指南"></a>

### 达尔文乐园：新手入门指南

适用版本：2026-11-01 当前功能，Windows 键盘与鼠标操作。

你可以在星球上投放生命、观察基因和环境怎样影响生存，也可以进入某个实体的视角亲自行动。第一次游玩，先完成“创建世界 → 投放 → 查看 → 操控 → 保存”这条路线，再尝试蚁群、RTS和联机。

本文以默认配置为例；使用自定义基因或旧存档时，请以游戏面板中的实际状态和权限为准。

<a id="doc-53e49d4d3f01-1-第一局先完成这六件事"></a>

#### 1. 第一局先完成这六件事

<a id="doc-53e49d4d3f01-第一步创建自己的世界"></a>

##### 第一步：创建自己的世界

1. 主界面选择 **单人游戏 · 存档**，再选择 **创建新世界**。
2. 填写世界名称和种子。种子可以是整数或文字；第一次可以保留默认环境参数。
3. 点击创建，等待加载进度结束。
4. 进入后按 **P** 暂停，先熟悉界面。若快捷键没反应，先点击输入框外的空白位置。

新世界不会因为菜单背景里出现了星球，就已经开始模拟。真正进入世界后，底栏会显示日期和播放/暂停按钮。

<a id="doc-53e49d4d3f01-第二步投放第一批实体"></a>

##### 第二步：投放第一批实体

底栏左上方的左右箭头用于切换两页。点击右箭头进入第二页，找到 **随机生成 · 全星球**。

1. 模板选择“默认实体”，先输入 **20**，范围保留“仅陆地”。
2. 点击 **随机生成**，等待数量提示完成。生成按批次进行，可以点击“取消”停止后续生成。
3. 按P继续，以 **1倍速度**观察。

这20个体用于熟悉操作，不是完整生态循环的数量配方。随机生成会分散到星球各处，并不保证都在当前镜头附近。

想指定落点时，点击第二页的“默认生成”或模板槽，再到地表左键放置；也可以把槽位拖到地表。点击式放置可以连续进行，**右键或Esc取消放置**。右键生成槽可设置每次放置的数量。

<a id="doc-53e49d4d3f01-第三步找到并查看一个实体"></a>

##### 第三步：找到并查看一个实体

- 在星球视角中，**左键拖动**旋转视角，**滚轮**缩放。
- 在未放置、未进入RTS时，**右键活体**打开实体属性面板。
- 查看生命、饱食度、体型、生命阶段和当前活动；把鼠标移到基因行上，可查看该基因贡献的属性和说明。
- 点击标题旁的星形按钮收藏。第二页的“收藏列表”可以帮助你再次定位它。

默认实体拥有生长、繁殖、营养方式和环境适应等基础基因，通常依靠阳光自养。**没有有效移动能力时，保持静止是正常行为。**领地、种群等进阶谱系也可能提供行动能力，所以判断时要看实际表达和状态。

<a id="doc-53e49d4d3f01-第四步体验一个能移动的个体"></a>

##### 第四步：体验一个能移动的个体

单人游戏中可以编辑普通实体的基因。建议先暂停，再做一个小练习：

1. 右键打开一个普通实体的面板，点击“扩展基因”旁的 **＋**。
2. 选择 **行动基因**，输入数值后按回车或点击其他位置提交。
3. 在默认配置、没有额外抑制时，行动基因设为 **25** 通常对应“食草”。再添加 **异养基因**并设为 **75**（消化），才可击败附近静止实体后吸收其营养；只把父级营养方式设为80还不能代替独立异养能力。以面板显示的状态和是否生效为准。
4. 在它附近投放一些默认自养实体作为食物来源，再恢复1倍运行，观察饱食度降低后的觅食。
5. **双击这个活体**进入实体视角，尝试WASD移动、鼠标转向、空格跳跃；按Tab返回星球视角。

获得行动能力后不能继续假定它能靠原有方式自养。是否能移动、进食和攻击，还受基因表达、体型、环境及当前状态影响。

<a id="doc-53e49d4d3f01-第五步看懂地图统计"></a>

##### 第五步：看懂地图统计

切回 **第一页**，右侧“地图实体统计”显示：

| 项目 | 含义 |
| --- | --- |
| 实体总数 | 全地图存活实体数，包含镜头外个体 |
| 幼年／成年／老年 | 当前存活个体的生命阶段分布 |
| 基因筛选 | 选择一个基因，查看相关数量 |
| 携带 | 有这个基因的实体数；同一个体的复制基因只计一次 |
| 生效 | 当前实际表达该基因的实体数 |
| 占比 | 携带个体占全体存活实体的比例 |

“携带”多于“生效”通常说明部分个体的基因被禁用或受到抑制。筛选用于观察，不会只让筛选中的实体运行。

<a id="doc-53e49d4d3f01-第六步保存并离开"></a>

##### 第六步：保存并离开

按 **Esc** 打开菜单，选择 **保存并返回主界面**。之后从单人游戏存档列表再次进入。

默认每120秒自动保存；正常退出也会尝试保存。保存失败时先查看提示，不要把强制关闭程序当作保存操作。联机世界由房主统一保存。

<a id="doc-53e49d4d3f01-2-先分清这三类物体"></a>

#### 2. 先分清这三类物体

| 外观或标记 | 是什么 | 可以做什么 |
| --- | --- | --- |
| 普通实体模型 | 存活个体 | 右键查看属性；双击尝试操控，具体能力取决于基因和权限 |
| 暖色叉号、较深色球体 | 死亡后未被吸收的营养形成的尸体 | 右键查看死亡、营养和搬运信息；可由工匠运输或被食腐实体吸收，不计入存活总数 |
| 黄色发光块 | 能量或种群补给 | 右键查看资源信息；符合条件的实体可自动吸收 |

新产生的尸体会记录生前名称和体型。旧存档没有记录的字段会显示“旧存档未记录”。查看尸体不会把它变回活体。

<a id="doc-53e49d4d3f01-3-基因营养和繁殖怎么理解"></a>

#### 3. 基因、营养和繁殖怎么理解

先记住三个区别：

- **有基因，不一定生效。**基因会相互促进或抑制，环境和角色也会改变表达。输入值后，检查实际状态、有效属性和提示说明。
- **饱食，不等于储备充足。**进食先补饱食度，溢出部分进入储存；繁殖会检查成年、储备和其他条件。
- **营养方式，不等于营养利用。**前者决定自养或异养等方式；独立的营养利用基因与通用能量块的吸收、吐出有关。
- **异养分为寄生和消化。**寄生幼体隐藏自身、跟随更大的宿主吸收饱食度，宿主显示“（被寄生）”，成年后脱离并独立消化取食。消化只在击败后结算，未吸收完的营养留下尸体；食腐是异养的出错分支，吸收尸体余量。
- **卵寄生属于繁殖。**它向宿主放入外来卵，宿主显示独立的卵寄生孕育状态，卵的后代基因来自亲本，与宿主无关。

普通繁殖通常需要成年及足够储存营养；有性繁殖还需要合适配偶。怀孕和产后休养需要时间，不能以“刚生成就没有后代”判断出错。实体上限已满时，已完成孕育的个体会等待空位。

同一实体的多个复制基因可能叠加表达，但生产、移动、繁殖等关键行为不会因此重复推进。士兵、工匠等固定分工的遗传基因受到锁定，无法像普通实体一样随意修改。

<a id="doc-53e49d4d3f01-把喜欢的基因组合保存为模板"></a>

##### 把喜欢的基因组合保存为模板

在实体面板顶部点击 **存为模板**。第二页的模板槽及随机生成列表可使用它。模板归属于当前世界，退出重进后保留，不同存档之间不共享。旧版全局模板文件保留；需要时在第二页点击 **导入旧模板**，只向当前世界补入缺失且基因定义兼容的模板，同名模板不会被覆盖。

模板保存的是可再次生成的基因组合，**不是当前个体的完整游戏进度**。要保留它的年龄、营养、位置和孕育状态，应保存世界。

营养利用是储存基因出错演化的分支。想进一步调整基因的进化、促进或抑制关系，可从主界面进入“工具 · 基因树编辑器”，按[基因树工具说明](入门与交互.md#doc-7d4f16f6593a)操作；这与只修改某个实体的基因值是不同的功能。

<a id="doc-53e49d4d3f01-4-实体视角操作"></a>

#### 4. 实体视角操作

| 操作 | 功能 |
| --- | --- |
| 双击活体 | 进入实体视角 |
| WASD／鼠标 | 移动／转向 |
| 左键／空格 | 攻击／跳跃，受实际能力限制 |
| 按住Alt | 释放鼠标；松开后恢复操控 |
| P | 启动或暂停模拟；联机需要管理或作弊权限 |
| Q | 有生效营养利用基因且营养足够时，消耗自身营养吐出能量块 |
| Tab | 返回星球视角 |
| Esc | 打开菜单；返回后保留操控对象 |

暂停、按住Alt、正在输入文字或基因不满足条件时，相应行动可能不执行。当前没有E键免费添加能量块的功能。

陆地行动能力不等于游泳能力。进入水中后无法继续按陆地方式移动，并可能溺水。移动速度和跳跃也受体型及最大能力限制。

<a id="doc-53e49d4d3f01-5-学会管理规模和环境"></a>

#### 5. 学会管理规模和环境

<a id="doc-53e49d4d3f01-给这个存档设置实体上限"></a>

##### 给这个存档设置实体上限

第一页统计卡右上角点击 **齿轮 → 本存档游戏设置**，输入上限并点击“保存设置”。

- 默认上限为 **3000**，**0表示不限**。
- 上限同时约束投放、随机生成和繁殖。
- 降低上限不会删除已有个体；超过上限的旧存档仍会完整加载。
- 设置属于当前存档，与主菜单中的音量、画质设置分开。

第一页底部的 **清除全部实体** 会清除全地图实体并保存结果，**不按当前基因筛选范围清除**。需要保留进度时，先备份存档再使用。清理后留下的尸体、能量块属于资源，不计入存活总数。

<a id="doc-53e49d4d3f01-调整温度湿度地形和种子"></a>

##### 调整温度、湿度、地形和种子

在第一页点击相应参数按钮，修改输入值或滑条，再点“应用”或按Shift提交。地形参数中的数值是 **陆地比例百分比**。

更新时会出现加载动画，完成后返回原世界和镜头，恢复原来的运行或暂停状态。温湿度修改只重算气候；地形和种子修改才重建地表。实体身份与游戏时间保留，地形变化后实体落点会适配新地表。

<a id="doc-53e49d4d3f01-觉得卡顿时先看哪里"></a>

##### 觉得卡顿时先看哪里

左上角显示FPS和平均帧耗时；发生模拟积压时，还会显示实际模拟倍率和待算时间。

先降到1倍，再观察数量和帧耗时。右键播放/暂停按钮可选择倍率。**选择16倍不代表机器一定完成16倍模拟**；大量个体、繁殖或复杂种群都会增加负担。先小规模熟悉功能，再逐步增加数量，不要依靠无限生成测试完整生态。

<a id="doc-53e49d4d3f01-6-进阶观察蚁群"></a>

#### 6. 进阶：观察蚁群

拥有种群基因且处于蚁群状态时，会形成王后和分工。活动后面的括号表示角色，例如“巡逻（士兵）”“运输（工匠）”。

| 角色 | 主要作用 |
| --- | --- |
| 王后 | 繁殖与维持种群，不能战斗，也不能被挑战替换 |
| 士兵 | 主动猎杀符合条件的外群目标，留下尸体，不直接吸收击杀营养 |
| 工匠 | 搬运尸体或不能移动的活体，转化为种群补给，不能正常战斗或繁殖 |
| 繁殖个体 | 成年后离群建立自己的种群 |
| 专用配偶 | 有性王后的繁殖伙伴，不进行独立繁殖 |

王后及幼体与成年成员使用不同的补给规则。看到黄色块却没有进食时，先确认角色、补给类型、距离和营养容量。

第一页的“种群”图层可观察不同种群的范围。同群识别影响攻击判断；普通领地巡逻有休息，只在真实受击后反击，蚁群士兵则可主动猎杀外群目标。

更详细的流程见[蚁群与巡逻](生态与种群.md#doc-26dabc11f2af)。

<a id="doc-53e49d4d3f01-7-进阶用rts指挥实体"></a>

#### 7. 进阶：用RTS指挥实体

1. 在星球视角按 **R** 进入RTS。
2. 左键拖出方框选择实体，按住Shift追加选择。
3. 右键地面下达移动指令；右键可攻击目标时会按条件攻击。
4. 使用权能栏上方的命令条选择攻击、采集、守卫或停止，具体操作取决于所选实体的实际基因和角色。
5. 再按R退出。RTS中用 **中键拖动**旋转镜头。

无有效行动能力的实体不会因为收到命令就能移动，工匠和王后也不会因此获得攻击能力。RTS中的右键用于下令；想按普通方式右键查看属性，先退出RTS。

单人管理员可以指挥符合权限的实体。联机普通成员操控王后时，只能指挥自己的种群，不能夺取其他玩家正在操控的实体。

<a id="doc-53e49d4d3f01-8-与朋友进行局域网游戏"></a>

#### 8. 与朋友进行局域网游戏

**房主：**先进入单人世界，按Esc，选择“对局域网开放”，设置端口和作弊开关，再点击“开始开放”。把菜单显示的局域网IP和端口告诉成员；默认端口为 **47777**。

**成员：**主界面选择“多人游戏”，填写房主IP、相同端口和自己的名称，加入后选择尚未被占用的实体。

| 身份 | 可用能力 |
| --- | --- |
| 房主／唯一管理员 | 管理世界、基因、投放、上限、清除、模拟时间与房间设置 |
| 普通成员 | 选择实体游玩和查看信息；不能编辑基因、投放、修改上限或清除；操控王后时可指挥本群 |
| 开启作弊的成员 | 获得世界编辑能力，但不能自行开关作弊或关闭房间 |

普通成员只能在进入游戏或自身实体死亡后重新选择；作弊开关不会增加第二名管理员。联机中某个玩家打开Esc菜单不会暂停全体，世界由房主统一保存。

详细步骤见[局域网与RTS](入门与交互.md#doc-edc1338a5e16)。

<a id="doc-53e49d4d3f01-9-常见问题速查"></a>

#### 9. 常见问题速查

| 遇到的情况 | 先检查什么 |
| --- | --- |
| 实体不动 | 是否暂停；是否有生效的移动能力；是否在水中、孵化、被搬运或受其他状态限制 |
| 能动但没有攻击 | 食性、是否需要进食、感知和距离、目标体型、同群关系，以及角色是否允许攻击 |
| 有基因却没效果 | 看“生效／失效”、表达属性和悬停提示；检查环境及其他基因的抑制 |
| 成年后仍不繁殖 | 储存营养、配偶、孕育/休养时间、角色限制和实体上限 |
| 黄色能量块就在旁边仍不吃 | 普通个体检查营养利用基因；蚁群检查补给类型、角色、距离和是否已满仓 |
| 深色球体无法当活体操控 | 看叉号及右键信息，可能是已死亡的尸体资源 |
| 右键只下令、不打开面板 | 先按R退出RTS；若正在投放，先取消投放 |
| 放不出更多实体 | 是否达到本存档上限、是否有管理权限、是否正在更新世界或点击在UI上 |
| 按键没有反应 | 是否在输入框中、菜单是否打开、是否暂停，以及联机权限是否允许 |
| 统计与眼前数量不同 | 统计包含全地图存活个体，排除尸体等资源；基因“携带”和“生效”也是不同口径 |

<a id="doc-53e49d4d3f01-需要反馈问题时"></a>

##### 需要反馈问题时

在设置中点击 **打开日志文件夹**，保留对应时间的日志；同时记下发生步骤、世界名称、实体数量和模拟倍率，附上截图。联机问题由房主与成员分别保留日志。

## 主界面与存档流程说明

原文档：`Docs/操作指南/主界面与存档流程说明.md`

<a id="doc-d2db83a500d7-主界面与存档流程2026-10-26"></a>

### 主界面与存档流程（2026-10-26）

- 单人游戏进入存档列表，可以读取已有世界或创建新世界。
- 新世界支持世界名字、数字或文字种子、陆地比例、平均温度和平均湿度。名字留空时采用本地现实时间_实际种子，例如 `2026-10-26_23-05-06_742031`。文字种子会稳定转换为整数。
- 存档保存在游戏目录 `save`，每个世界一个独立标识文件夹，主文件为 `save/<世界标识>/world.json`。每 120 秒自动保存；点击退出游戏时先保存，失败会显示原因并留在游戏。覆盖保存保留 `.bak` 备份。
- 工具“保存并应用”默认写入游戏目录 `mods/Default`，基因 JSON 位于其 `Genes` 子目录。
- 游戏中 Esc 打开菜单，包含“返回游戏 / 设置 / 保存并返回主界面 / 退出游戏”和“对局域网开放”；再次按 Esc 返回。单人时暂停，联机时不因某个玩家打开菜单而暂停整个对局。F10 无退出或返回功能。实体操控中 Tab 返回星球视角，Esc 返回保留操控对象。
- 进入世界后先显示加载阶段及百分比。地形、气候计算在后台执行，实体恢复分帧执行。加载完成后的下一帧开始累计模拟时间；旧存档恢复原有游戏时间与暂停状态。
- 设置页左侧提供“声音与画面”“按键控制”“日志与诊断”分页。在按键控制页点击现有绑定即可修改，支持鼠标、冲突提示、自动保存和恢复默认。Esc取消正在等待的改键；没有等待改键时返回原菜单。游戏中通过Esc菜单进入设置，底栏保留原分页按钮。联机设置仅影响本机。
- 主菜单使用提前录制的实际游戏星球画面：地球自转、太阳绕地球公转、星空背景。视频位于 `Assets/StreamingAssets/Menu/earth-orbit.webm`，VP8、1280×720、24fps、12 秒循环，无音轨；同目录 JPG 用于解码前封面。采用软件解码避开Windows原生H.264解码的Flush报错。

<a id="doc-d2db83a500d7-验证"></a>

#### 验证

已通过实际新建、保存、读档回归：默认名字、目录、稳定文字种子、加载时钟、实体和收藏、矿量、时间倍率、暂停状态、覆盖备份、损坏存档清场前拦截。详细结果：`Artifacts/WorldFlowReview/result.txt`。

Unity 编辑器 Tools → Darwin Park 提供 Validate World Flow、Capture World Flow 与 Record Menu Background。回归会创建一个临时验证世界；录制需要先加载世界，并要求 PATH 中能找到 ffmpeg。发布游戏播放已有视频不需要 ffmpeg。

- 返回主界面前必须保存成功，随后清理当前实体、收藏与基因快照；可以重新选档或新建世界。保存失败留在暂停页。
- 旧 save/<世界标识>.json 仍可读取；首次成功保存到新目录后，旧档及备份保留为该世界目录内的 legacy.json 和 legacy.json.bak。
- 旧世界增量补齐新基因，已有同名基因定义保持原值；新增配置随下一次存档保存。
- 联机客户端离开时直接清理内存副本，不保存管理员世界；管理员保存规则沿用单人流程。加入与权限详见[局域网与 RTS](入门与交互.md#doc-edc1338a5e16)。

<a id="doc-7d4f16f6593a-第一人称"></a>

#### 第一人称
双击实体后进入锁定第一人称，WASD 移动、鼠标转向、左键攻击、空格跳跃、Tab 返回星球。Esc 打开暂停面板，返回游戏后保留操控目标。滚轮不再拉远。自身模型暂时隐藏但仍有碰撞，退出恢复。近身攻击保留原攻击距离、行动基因与冷却限制。

<a id="doc-7d4f16f6593a-工作台"></a>

#### 工作台

实体信息面板默认宽 520、高 560，保留滚动与小窗口边界适配。底栏第二页的“随机生成 · 全星球”宽 240，点击“选择实体”打开两列界面：左列完全按模板生成，右列选择基因必有/必无且其他基因随机。默认仅陆地，可切换全部地表；每批默认10个、最多200个，分帧完成，支持取消本批。种群比例调节默认关闭，开启后仅抑制超额类别的新孕育，不再直接生成；详见[随机生成与比例维持](生态与种群.md#doc-3f7f0ae64c5a)。切换底栏页面时任务继续，单人打开覆盖菜单会暂停未完成任务，切换世界则停止。联机时只有管理员和作弊成员可生成；房主打开菜单不会阻塞成员请求。

- 主界面 → 工具 · 基因树编辑器。
- 左侧读取内置和已保存的 JSON 基因。输入文件夹路径后点“读取 JSON”，可合并该文件夹内配置（文件名必须等于 id）。
- 从左侧拖到右侧画布；拖动已有节点调整位置。普通基因为方框，出错基因为菱形。

- 右键节点，右侧选择向下进化、侧向出错、红色抑制或绿色促进，再点目标节点连接。
- 右侧“菱形：出错基因”可更改节点外框。出错连线自动将目标显示为菱形。
- 右键连线可设置类型、数值或删除。进化/出错数值是目标的相对选择权重；抑制/促进数值沿用 coefficient 单位（源基因值 × coefficient ÷ 1000）。
- 右键节点可编辑名称、属性最小/最大值、状态中心值；高级 JSON 保留完整编辑能力。
- 属性区的“实体状态标签”从注册表自动列出，可给基因授予活动状态；不替换基因本身的巡逻/警戒等倾向。状态条件、阈值和迁移配置在 `entity_states.json`，保存时与基因一起导出。详见[实体状态注册表开发说明](../开发设计/基因与生态.md#doc-59989eca11b6)。
- 缩小/放大按钮与画布滚轮控制 15%～200% 缩放，中键拖动平移；“适应全图”一次查看所有节点，“100%”恢复原比例。缩放后节点选择、拖动、连线和拖入沿用图坐标。
- 层级列表与流程图共用同一份数据。Esc 取消正在建立的关系。
- “保存并应用”提交当前数值并保存；“重新读取”只在无未保存修改时执行；“放弃修改”恢复磁盘版本。

## 按键控制与游戏数值

原文档：`Docs/操作指南/按键控制与游戏数值.md`

<a id="doc-668332990f50-按键控制与游戏数值"></a>

### 按键控制与游戏数值

在主菜单或游戏内Esc菜单打开设置，左侧选择“按键控制”。点击当前按键后，按新的键盘或鼠标按键；Esc取消这次等待。改键立即生效并保存到本机偏好，下次启动继续使用。冲突会提示已有用途，恢复默认会一次重置全部绑定。Esc保留给菜单，星球视角暂停和实体跳跃允许共用空格，因为两者不同时生效。

支持前后左右、跳跃、攻击、按住释放鼠标、退出实体操控、吐出能量块、暂停/继续、星球视角暂停、RTS切换、切换图层和取消图层显示。默认L依次切换图层，反引号键（数字1左侧）取消图层显示；两者均可改键。输入框或覆盖菜单拥有输入时不触发。移动与攻击仍要求有效行动基因；改键不会绕过基因、体型、种群或联机权限检查。

<a id="doc-668332990f50-修改游戏数值"></a>

#### 修改游戏数值

编辑游戏目录的 `config/gameplay.json`，保存后约2秒自动载入，也可在设置页点击“重新载入数值配置”。编辑器中对应工程根目录的同名文件，Windows游戏中对应可执行文件旁的 `config` 文件夹。首次运行缺少文件时自动生成，内含中文字段注释，支持 `//` 行注释及 `/* */` 块注释。不要改 `version`。内容无效时日志会报告原因并保留上次有效配置；首次加载失败则使用内置默认值。

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| `baseMetabolismMultiplier` | 1 | 基础饱食消耗倍率；0关闭基础消耗 |
| `movementMetabolismMultiplier` | 1 | 行动饱食消耗倍率；0.5减半，2翻倍，0关闭行动消耗 |
| `repairFoodPerHealth` | 0.5 | 每恢复1生命值消耗的饱食度 |
| `starvationDamagePerSecond` | 1 | 饱食耗尽后每模拟秒生命损失 |
| `manualAimPadding` | 0.85 | 手动攻击选择框各方向额外扩大距离 |
| `manualHitboxScale` | 1.5 | 手动攻击选择框相对真实碰撞框的倍率，至少1 |
| `manualAttackReachBonus` | 0.35 | 手动近战距离额外容差；AI沿用原距离 |
| `supplyActivityRadiusRatio` | 1 | 补给点活动圆相对王后圆的半径倍率，必须大于0 |
| `colonyActivityRadiusMultiplier` | 0.35 | 王后/领袖活动圆相对旧版的半径倍率，初始范围缩小 |
| `populationFillOpacity` | 0.22 | 未单独设置种群的不透明度默认值，0完全透明、1不透明；已有单群设置优先 |
| `parthenogenesisWaitDays` | 5 | 孤雌生殖基因成年后连续无合适配偶的等待游戏日数；0立即尝试，仍需储粮及数量空位 |

消耗公式是：`基础代谢 × 世界基础倍率 × 全局基础倍率 + 行动代谢 × 世界行动倍率 × 实际切向速度 × 全局行动倍率`，再乘实际交付的模拟秒数。移动速度按模拟倍率换算，不使用显示帧率；暂停不推进饱食结算。其余数值必须为非负有限数字。

这份配置是可在运行时载入的全局设置，同时作用于新世界和已有存档。原世界的基因、蚁群和生态平衡快照继续保存自己的规则，全局倍率作用于最终结算。联机时生命及饱食结算由房主负责，房主应修改自己的配置。分发构建时可附带此文件；不附带时游戏首次启动会生成。

<a id="doc-668332990f50-攻击与种群范围"></a>

#### 攻击与种群范围

攻击判定扩大的是选择框，实体的物理体积保持原样。目标必须在准星前方，并通过真实视线遮挡检查；墙体和地形仍会阻挡，选中后还要满足实际近战距离。

蚁群活动区是王后圆和实际剩余能量的专属补给圆的并集。王后出生不预建空检查点，运输计划及旧档空点不扩张范围，补给耗尽后扩展范围消失。种群图层默认以半透明填色显示，重叠区不重复加深；右键种群图层按钮切换合并外轮廓，内部交叉线不保留。士兵巡猎、巡逻及工匠新采集任务共用该范围。

种群档案已移到第二页，点击“全部种群列表”浏览存活及已灭绝种群。独立详情提供颜色设置、基因/年龄扇形图或柱状图、成员、发展历史和多代衍生关系；详见[种群档案与发展谱系](生态与种群.md#doc-cf47514a7827)。

## 实体面板与体型行动

原文档：`Docs/操作指南/实体面板与体型行动.md`

<a id="doc-6e9e9f70f41e-实体面板与体型行动"></a>

### 实体面板与体型行动

实体详情面板将生命阶段、当前活动和气候分行显示。蚁群的固定出生分工附在实际状态之后，例如“巡逻（士兵）”“运输（工匠）”“准备繁殖（王后）”。不再显示捕猎、采集、集结、守卫和挑战按钮区。

基因行的图标、名称和数值使用独立的区域；带实体状态标签的基因另留标签行。士兵、工匠等已锁定遗传基因的个体，其数值框显示为不可编辑。悬停提示列出本基因真正贡献的属性，失效基因显示零贡献，不会借用实体中其他基因的属性值。

<a id="doc-6e9e9f70f41e-行动属性继承"></a>

#### 行动属性继承

行动、领地、种群属于同一行动谱系。移动、感知、跳跃和攻击等共有能力由基础谱系提供一次；领地只列出领地半径与防御，种群只列出光环和协同等专属属性。添加进化基因不会重复叠加共有能力。

只有领地或种群基因的个体仍可继承基础行动能力。同一种基因的复制保留原有复制强度规则。旧世界中重复定义的行动属性在运行装载时规范化，原始存档和自定义配置文件不会被自动覆盖。

蚁群王后由固定分工决定，不能通过狼群的决斗机制替换；这一限制在挑战逻辑入口执行，与界面是否显示按钮无关。

<a id="doc-6e9e9f70f41e-体型与上限"></a>

#### 体型与上限

移动速度沿用基础行动基因的体型反比规则，并在群体与角色倍率计算后执行上限。跳跃能力按体型平方根的反比缩放，真正起跳使用该能力和组件跳跃上限中的较小值。

参数位于 `Assets/Resources/Entities/locomotion_settings.json`：

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `maximumMoveSpeed` | 12 | 每模拟秒的最大主动移动速度；时间倍率仍正常加速模拟 |
| `maximumJumpSpeed` | 8 | 体型换算后的最大跳跃能力；实际冲量还受跳跃组件限制 |
| `minimumMovementSize` | 0.25 | 跳跃体型换算的最小参与值，避免除零与极小体型放大 |
| `jumpSizeExponent` | 0.5 | 跳跃能力的体型制约指数 |
| `wanderSpeedRatio` | 0.35 | 无捕食目标时的漫游速度比例 |
| `movingFriction` | 0 | 主动运动中的本实体摩擦 |
| `stationaryFriction` | 1 | 静止实体的地面摩擦 |

AI 与玩家共用移动上限。暂停、孵化、搬运、寄生及陆地实体不能在水中行动的原有约束仍然有效。

## 局域网与RTS

原文档：`Docs/操作指南/局域网与RTS.md`

<a id="doc-edc1338a5e16-局域网与-rts"></a>

### 局域网与 RTS

<a id="doc-edc1338a5e16-开放和加入"></a>

#### 开放和加入

1. 管理员先进入一个单人世界，按 Esc，点击“对局域网开放”。
2. 选择端口及是否开启作弊模式，点击“开始开放”。默认端口为 47777，菜单显示管理员的局域网 IP。
3. 其他玩家在主界面点击“多人游戏”，填写管理员 IP、相同端口和自己的名称，点击“加入游戏”。
4. 加载完成后选择一个尚未被占用的实体开始游玩。普通成员只能在首次进入或所操控实体死亡后重新选择。

同一程序同时包含服务端和客户端。房主是唯一管理员；最多 8 名成员，容量可在 `Assets/Resources/Entities/lan_multiplayer.json` 修改。房主打开 Esc 菜单不会暂停整个对局。

<a id="doc-edc1338a5e16-权限"></a>

#### 权限

| 操作 | 管理员 | 普通成员 | 开启作弊的成员 |
| --- | --- | --- | --- |
| 选择未占用实体游玩 | 可以 | 进入或死亡后选择 | 可以更换 |
| 修改名称、基因值、添加基因 | 可以 | 禁止，控件只读或隐藏 | 可以 |
| 放置实体、模板、全星球随机生成 | 可以 | 禁止，生成页不可用 | 可以 |
| 修改世界参数、基因树、模拟时间 | 可以 | 禁止 | 可以 |
| RTS 指挥 | 未被其他玩家占用的实体 | 王后自己的种群 | 未被其他玩家占用的实体 |
| 开关作弊、关闭局域网 | 可以 | 禁止 | 禁止 |

作弊开放世界编辑能力，不产生第二名管理员。关闭作弊立即撤回成员的编辑权限。所有修改及指令都由服务端验证，隐藏按钮之外也有权限检查。

<a id="doc-edc1338a5e16-操控与-rts"></a>

#### 操控与 RTS

实体操控继续使用 WASD、左键攻击、空格跳跃；按住 Alt 唤出鼠标，松开恢复。P 启停模拟仅管理员及作弊成员可用。Q 吐出能量块仍要求自身营养利用基因生效并有足够营养，由服务端扣除实际能量。

按 R 进入或退出 RTS：左键拖出方框，Shift 追加选择，中键转动镜头，右键下达移动指令；右键可攻击目标时自动攻击。下方命令栏可以选择攻击、采集或守卫，再右键指定目标；“停止”立即停止。采集指令交给原有工匠运输系统，不会复制尸体或货物。

命令依照实际基因和角色开放：无有效行动能力的实体不能移动，王后和工匠不能使用战斗攻击，采集搬运只供工匠。普通成员操控王后时可以进入 RTS，框选及服务端指令都仅限该王后自己的种群。管理员也不能夺取其他玩家正在操控的实体。

<a id="doc-edc1338a5e16-保存与离开"></a>

#### 保存与离开

房主统一运行模拟并保存世界，包括远端基因修改、实体及 RTS 指令。客户端使用内存中的世界副本，不把房主世界写入自己的存档目录；作弊成员在局内应用基因树也不会覆盖房主电脑上的任意文件。

成员可在 Esc 离开联机。房主关闭局域网后继续单人游戏，成员返回主界面；房主退出时同样结束房间。断线会释放所占实体，之后可重新加入。加载过程中断线会停止加载并清场。当前不提供房主迁移。

已完成同机两个独立 Unity 进程的真实 TCP 测试；尚未使用两台物理电脑验收局域网连接。

## 权能栏统计与帧率

原文档：`Docs/操作指南/权能栏统计与帧率.md`

<a id="doc-dd2184399f94-权能栏统计与帧率"></a>

### 权能栏统计与帧率

“地图实体统计”现在只显示在权能栏第一页参数按钮右侧。宽度260逻辑单位；管理员卡片高度164，含底部清理按钮，普通成员使用136高的只读卡片：

- **实体总数**：当前地图所有存活实体，包含镜头外的个体；排除生命归零、已移除或停用的实体。
- **年龄分布**：幼年、成年、老年数量。
- **基因筛选**：从当前世界的基因列表选择一个基因，显示携带该基因的实体数量、当前表达生效的实体数量，以及携带个体占全体的百分比。

同一实体即使有多个复制基因，也只计一个携带者。被禁用或抑制的基因可能仍被携带，但不计入生效数。选择“全部实体”返回总体信息。筛选只用于观察，普通联机成员也可以使用。

统计默认每 0.5 秒更新，出生、死亡、基因变化及联机同步后会随之更新；离开世界时归零。


<a id="doc-dd2184399f94-组合筛选与实体列表"></a>

#### 组合筛选与实体列表

统计卡右侧新增“实体筛选”。空间不足时，点击统计标题旁的“筛选”按钮，在底栏上方展开条件。

1. 在“包含”下拉框选择一个或多个基因；实体必须携带全部所选基因。
2. 在“不包含”下拉框选择一个或多个基因；携带其中任意一个的实体都会排除。
3. 已选项会标注“已选”，再次选择可取消；“清空本组条件”只清除该组，“重置”清除全部条件。同一基因不能同时包含和排除，最后一次选择决定所属组。

展开的下拉菜单可通过点击外部、再次点击展开按钮或按Esc收起；选择项目后自动收起。Esc优先关闭下拉，不会同时打开暂停菜单。切换底栏页面或隐藏HUD也会清理弹出列表。
4. 匹配数量显示为“匹配 N / 当前存活实体总数”。点击“查看实体列表”，可分页查看名称，点击实体定位镜头，右键查看其属性。

例如：包含“生长基因”，不包含“行动基因”，可找到携带生长基因但没有行动基因的个体。这里的“携带”包含被禁用、抑制或未生效的基因；不要把基因不生效当成没有基因。

列表默认每页最多10项，复用固定数量的行，少量结果时自动缩短。出生、死亡、基因增删后默认每0.5秒更新；实体刚死亡或移除时不会继续定位失效引用。切到第二页或离开世界会关闭列表。

组合条件与原统计卡的单基因“携带/生效”统计独立。组合筛选只查询和定位，普通联机成员也能使用；不会改变实体、开放编辑权限或改变“清除全部实体”的范围。筛选条件不写入存档。

按 R 进入 RTS 后，操作栏位于整条权能栏上边缘的外侧，跟随实际 Canvas 缩放，留有间距。点击命令或统计下拉菜单不会同时触发地面指令。

左上角显示 FPS 和平均帧耗时，每 0.5 秒刷新，使用真实帧时间。暂停、16 倍模拟或打开菜单时仍显示实际渲染帧率。原实体面板下移以留出 FPS 的空间。

机器承载不足时，FPS下方额外显示实际完成的模拟倍率和待算秒数。高倍率不会在一帧无限补算，暂停不会增加待算时间；恢复后渐进处理。显示的FPS来自渲染帧耗时，不能把选择16倍理解为机器始终完成16倍模拟。


右上角齿轮打开“本存档游戏设置”，可输入实体上限，保存立即写入当前世界。新世界及缺少该字段的旧档默认3000，0表示不限。上限同时限制投放、随机生成和繁殖；降低上限不删除已有个体，读档完整恢复已有实体。满额的完成孕育等待空位，不伪造后代。

全局设置通过主菜单或Esc菜单进入，左侧分页包含按键控制，可修改并保存操控按键。底栏不再显示先前误加的设置按钮；统计栏右上角仍是本存档实体上限设置。

底部“清除全部实体”一键清除整个地图的实体，并保存清除结果；当前基因筛选不缩小清除范围，同时取消未完成的随机生成任务。联机中普通成员仍能查看第一页统计，但看不到创造、设置或清除按钮；管理员及开启作弊的成员可操作，服务端再次验证权限。

修改温度、湿度、种子或地形时，复用加载进度动画，在原世界中后台计算，完成后恢复原镜头及原先的运行/暂停状态。温湿度只重算气候；种子和地形才重建地表。地形参数为陆地比例百分比，不再误写湿度。更新期间不能继续修改或投放，进度结束后恢复操作。

右键深色的尸体资源可打开只读属性，显示死亡状态、剩余营养及搬运状态；新尸体还记录生前名称和体型。尸体有暖色叉号标记，不计入存活实体总数。旧存档没有记录的来源属性会明确标为未记录。

种群档案入口位于第二页，打开完整列表可搜索存活/灭绝种群、查看基因和年龄图表、发展历史及衍生谱系，并单独配置显示颜色。第一页保留实体统计及筛选。种群范围默认半透明填色，按钮右键切换合并外轮廓；左键再次点击关闭且取消绿色高亮。L依次切换图层，反引号键取消显示，设置页可修改两项按键。

# 存档详情与删除

在“选择存档”页面右键任意存档卡片，可打开详细信息，查看实体数量、幼体/成年/老年分布、孕育和收藏数量、世界种子、游戏时间、创建/保存时间、版本、文件大小及位置。数据来自上次保存的快照，查看详情不会加载或运行世界；损坏存档会显示读取错误。

详情页点击“删除存档”后，需要再次点击“确认删除”。取消或按 Esc 会先收起确认；再次按 Esc 返回存档列表。正在使用的世界需要先保存并退出，才能删除。左键“进入世界”仍按原方式读档。

删除会将整个世界目录及其附件、备份移到 `save/.deleted/<时间-标识>/`，并从列表移除。同一世界遗留的旧单文件也一并归档，避免删除后再次出现。恢复时退出游戏，将归档内的世界目录或旧 JSON 文件移回 `save`，再刷新列表。不要覆盖同名的现有世界文件。

# 模板删除与球形导航

轨道镜头与球形小地图可连续跨越南北极，经过极点后也能继续、横向或反向拖动，不必先缩放镜头脱离极点。方向会随连续旋转保留，不在极点强制翻回世界向上。

第二页每个已保存模板右上角新增“×”。点击后进入确认窗口，再点击“确认删除”才会删除模板；也可以右键模板，在数量窗口中选择“删除此模板”。删除会保存到模板文件，并刷新模板槽位和选择来源，不删除世界中已生成的实体。默认实体槽不提供模板删除按钮。

切换底栏页面会关闭放置数量/删除确认窗口并结束连续投放。来源槽位失效、模板刷新、打开菜单或权限撤回时，也会关闭窗口；按 Esc 先关闭该窗口。

第一页最右侧为球形小地图，显示当前世界的陆地、高地、海洋与淡水。按住左键拖动球面，主摄像头会同步转动，保留当前观察距离，并避免穿进地形。小地图只在第一页显示，导航不消耗模拟时间，暂停时也可使用；松开、切页或窗口失去焦点会释放拖动控制。

## 2026-11-17：模板归属、存档备份与天空

模板保存在 `save/<世界标识>/templates/entities.json`，不同世界独立；升级游戏、保存和重启不会改变归属。旧 `templates/entities.json` 不会被删除或自动分发，在第二页点击“导入旧模板”可补入当前世界。数量设置与删除确认窗口已压缩高度，保留确认、取消提示和删除入口。

先保存并退出世界，在选择存档界面右键卡片进入详情，点击“备份存档”。备份包含完整世界、该世界的模板及附件，保存在 `save/.backups`。复制和逐文件校验全部完成后才发布；复制失败的半成品不会成为最新备份。详情中可点击“从最新备份恢复为新存档”，生成暂停状态的新世界副本，原存档不被覆盖。备份损坏会拒绝恢复。当前入口提供最新备份恢复；独立备份不会随删除原存档而丢失。

进入实体控制视角后，鼠标上下移动可抬头和低头；暂停只停止实体行动，仍可转动视线。天空大气随太阳方向变化，白天偏蓝、晨昏地平线偏暖、夜间变暗。恢复运行后昼夜继续推进；三组颜色可在 `config/atmosphere.json` 修改，保存后约两秒生效，详见[大气层颜色配置](配置与诊断.md#大气层颜色配置)。晨昏范围及夜间散射强度保留在星球的天气表现组件中。

普通观察视角同样可以看到星球日面、夜面和随太阳移动的晨昏线。晨昏暖色只出现在对应的球面区域，不会因为摄像机处在晨昏方向就给整颗星球加红圈；切换数据图层时仍保持地图清晰。暂停会冻结太阳相位，恢复运行后继续昼夜交替。
