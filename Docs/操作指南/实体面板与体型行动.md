# 实体面板与体型行动

实体详情面板将生命阶段、当前活动和气候分行显示。蚁群的固定出生分工附在实际状态之后，例如“巡逻（士兵）”“运输（工匠）”“准备繁殖（王后）”。不再显示捕猎、采集、集结、守卫和挑战按钮区。

基因行的图标、名称和数值使用独立的区域；带实体状态标签的基因另留标签行。士兵、工匠等已锁定遗传基因的个体，其数值框显示为不可编辑。悬停提示列出本基因真正贡献的属性，失效基因显示零贡献，不会借用实体中其他基因的属性值。

## 行动属性继承

行动、领地、种群属于同一行动谱系。移动、感知、跳跃和攻击等共有能力由基础谱系提供一次；领地只列出领地半径与防御，种群只列出光环和协同等专属属性。添加进化基因不会重复叠加共有能力。

只有领地或种群基因的个体仍可继承基础行动能力。同一种基因的复制保留原有复制强度规则。旧世界中重复定义的行动属性在运行装载时规范化，原始存档和自定义配置文件不会被自动覆盖。

蚁群王后由固定分工决定，不能通过狼群的决斗机制替换；这一限制在挑战逻辑入口执行，与界面是否显示按钮无关。

## 体型与上限

移动速度沿用基础行动基因的体型反比规则，并在群体与角色倍率计算后执行上限。跳跃能力按体型平方根的反比缩放，真正起跳使用该能力和组件跳跃上限中的较小值。

参数位于 `Assets/Resources/Entities/locomotion_settings.json`：

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `maximumMoveSpeed` | 12 | 每模拟秒的最大主动移动速度；时间倍率仍正常加速模拟 |
| `maximumJumpSpeed` | 8 | 体型换算后的最大跳跃能力；实际冲量还受跳跃组件限制 |
| `minimumMovementSize` | 0.25 | 跳跃体型换算的最小参与值，避免除零与极小体型放大 |
| `jumpSizeExponent` | 0.5 | 跳跃能力的体型制约指数 |
| `wanderSpeedRatio` | 0.35 | 无捕食目标时的漫游速度比例 |
| `movingFriction` | 0 | 主动运动中的本实体摩擦 |
| `stationaryFriction` | 1 | 静止实体的地面摩擦 |

AI 与玩家共用移动上限。暂停、孵化、搬运、寄生及陆地实体不能在水中行动的原有约束仍然有效。
