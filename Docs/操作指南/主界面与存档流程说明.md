# 主界面与存档流程（2026-10-26）

- 单人游戏进入存档列表，可以读取已有世界或创建新世界。
- 新世界支持世界名字、数字或文字种子、陆地比例、平均温度和平均湿度。名字留空时采用本地现实时间_实际种子，例如 `2026-10-26_23-05-06_742031`。文字种子会稳定转换为整数。
- 存档保存在游戏目录 `save`，每个世界一个独立标识文件夹，主文件为 `save/<世界标识>/world.json`。每 120 秒自动保存；点击退出游戏时先保存，失败会显示原因并留在游戏。覆盖保存保留 `.bak` 备份。
- 工具“保存并应用”默认写入游戏目录 `mods/Default`，基因 JSON 位于其 `Genes` 子目录。
- 游戏中 Esc 打开菜单，包含“返回游戏 / 设置 / 保存并返回主界面 / 退出游戏”和“对局域网开放”；再次按 Esc 返回。单人时暂停，联机时不因某个玩家打开菜单而暂停整个对局。F10 无退出或返回功能。实体操控中 Tab 返回星球视角，Esc 返回保留操控对象。
- 进入世界后先显示加载阶段及百分比。地形、气候计算在后台执行，实体恢复分帧执行。加载完成后的下一帧开始累计模拟时间；旧存档恢复原有游戏时间与暂停状态。
- 主菜单使用提前录制的实际游戏星球画面：地球自转、太阳绕地球公转、星空背景。视频位于 `Assets/StreamingAssets/Menu/earth-orbit.mp4`，1280×720、24fps、12 秒循环，无音轨；同目录 JPG 用于解码前封面。

## 验证

已通过实际新建、保存、读档回归：默认名字、目录、稳定文字种子、加载时钟、实体和收藏、矿量、时间倍率、暂停状态、覆盖备份、损坏存档清场前拦截。详细结果：`Artifacts/WorldFlowReview/result.txt`。

Unity 编辑器 Tools → Darwin Park 提供 Validate World Flow、Capture World Flow 与 Record Menu Background。回归会创建一个临时验证世界；录制需要先加载世界，并要求 PATH 中能找到 ffmpeg。发布游戏播放已有视频不需要 ffmpeg。

- 返回主界面前必须保存成功，随后清理当前实体、收藏与基因快照；可以重新选档或新建世界。保存失败留在暂停页。
- 旧 save/<世界标识>.json 仍可读取；首次成功保存到新目录后，旧档及备份保留为该世界目录内的 legacy.json 和 legacy.json.bak。
- 旧世界增量补齐新基因，已有同名基因定义保持原值；新增配置随下一次存档保存。
- 联机客户端离开时直接清理内存副本，不保存管理员世界；管理员保存规则沿用单人流程。加入与权限详见[局域网与 RTS](局域网与RTS.md)。
