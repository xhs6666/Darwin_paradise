# Darwin Paradise · 达尔文乐园

一个基于 **Unity 6 + URP** 的星球生态模拟项目。生成自己的世界，投放和观察生命，调整环境与基因，查看生长、捕食、繁殖和变异带来的变化，也可以进入实体的第一人称视角亲自操控。

目前处于开发阶段，主要验证平台为 Windows。已实现局域网房主/成员联机与 RTS，支持管理员权限及作弊开关。最新改动与验证范围见[更新记录](CHANGELOG.md)。

![游戏内星球画面，主菜单循环动画的预录封面](Assets/StreamingAssets/Menu/earth-orbit.jpg)

第一次游玩可先阅读 **[新手入门指南](Docs/操作指南/新手入门指南.md)**，按创建、投放、查看、操控和保存逐步上手。

## 当前功能

- **程序化星球**：种子生成地形、海洋、山脉、盆地和峡谷，提供气候与矿脉图层，以及云层、大气和星空效果。
- **生态与基因**：数据驱动的基因表达、环境抑制、阶段变异、生命周期、捕食、繁殖与幼体生成。
- **实体交互**：投放、查看和修改基因、收藏定位，以及第一人称移动、攻击和跳跃。
- **基因树工具**：流程图和层级列表共用编辑数据，支持进化、出错、抑制、促进四类关系及 JSON 导入保存。
- **社会与寄生谱系**：行动出错产生领地，领地可演化出蚁群/狼群；支持领袖命令和决斗更替。营养方式下的异养基因支持寄生、消化，出错可产生食腐；卵生出错产生卵寄生，宿主承载独立卵体。详见[营养尸体与寄生](Docs/操作指南/营养尸体与寄生.md)。
- **蚁群分工**：出生时分配士兵、工匠或繁殖个体；所有实体死亡后的剩余营养形成尸体，工匠运输并转化为黄色能量块。王后与幼体使用育幼区，成年成员使用群内补给点；成年繁殖个体离群建立新种群。有性王后维持一名专用配偶，种群身份用于免伤与范围图层识别。详见[蚁群与巡逻说明](Docs/操作指南/蚁群与巡逻说明.md)。
- **基因实体状态标签**：保留基因倾向，通过注册表授予独立活动状态。普通领地巡逻有休息间隔，只在真实受击后反击；状态条件、巡逻频率和阈值均由 JSON 配置，随世界存档保存。配置与扩展方式见[实体状态注册表开发说明](Docs/开发设计/实体状态注册表开发说明.md)。
- **世界存档**：选择已有存档，或填写名字、种子、陆地比例和平均温湿度创建新世界。
- **局域网与 RTS**：Esc 开放房间，成员选择实体游玩；唯一管理员、服务端权限校验、可选作弊，王后成员仅能指挥本群。R 切换 RTS，框选并右键指挥，命令受基因及角色限制。
- **能量与模板**：储存出错可产生营养利用基因，自动吸收及消耗营养吐出能量块；模板跨会话保存，支持全星球分帧随机生成。
- **运行日志**：自动保存每次运行的输出、异常、存档和联机关键操作，支持轮转和用户目录回退；设置中可打开实际日志目录。
- **地图统计与 FPS**：权能栏右侧查看全地图存活实体与年龄分布，筛选基因携带数、生效数及占比；左上角显示真实帧率。详见[权能栏统计与帧率](Docs/操作指南/权能栏统计与帧率.md)。
- **种群档案**：第二页浏览全部已记录种群与成员，配置范围及标记颜色，切换基因/年龄扇形图和柱状图，查看发展历史及多代衍生关系；灭绝档案随世界保留。详见[种群档案与发展谱系](Docs/操作指南/种群档案与发展谱系.md)。
- **加载与暂停**：显示加载阶段和进度，加载完成后开始累计模拟时间；Esc 打开菜单，设置页左侧提供声音与画面、按键控制、日志与诊断分页；联机时打开菜单不会暂停整个对局。
- **预录主菜单背景**：播放游戏场景中地球自转、太阳围绕地球公转的循环动画，无需先生成可玩世界。

## 开始运行

### 环境

| 项目 | 版本 / 要求 |
| --- | --- |
| Unity Editor | **6000.3.14f1** |
| 渲染管线 | Universal Render Pipeline **17.3.0** |
| 仓库资源 | Git + Git LFS（贴图、视频等资源通过 LFS 管理） |
| 主要开发与验证平台 | Windows，键盘和鼠标 |
| 依赖安装 | Unity Package Manager 按 `Packages/manifest.json` 和锁定文件恢复 |

### 在编辑器中启动

1. 克隆仓库：

   ```bash
   git lfs install
   git clone https://github.com/xhs6666/Darwin_paradise.git
   cd Darwin_paradise
   git lfs pull
   ```

2. 在 Unity Hub 中添加仓库目录，使用上述 Unity 版本打开，等待资源与依赖导入完成。
3. 打开 `Assets/Scenes/SampleScene.unity`，点击 Play。
4. 选择 **单人游戏 · 存档**，读取已有世界，或点击 **创建新世界**。
5. 等待加载完成后开始游戏。新世界名称留空时，采用创建时的本地现实时间与实际种子，例如 `2026-10-26_23-05-06_742031`。种子可以填写整数或文字；文字会稳定转换为整数。

### 构建 Windows 游戏

在 Unity 的 **File → Build Profiles** 中选择 Windows，确认场景列表包含并启用了 `Assets/Scenes/SampleScene.unity`，再执行 Build 或 Build And Run。需要安装对应的 Unity 平台构建模块。

构建后的游戏需要保留 Unity 生成的数据目录；菜单视频随 `StreamingAssets` 一起打包。**正常运行不需要安装 FFmpeg。**

## 操作说明

| 场景 | 操作 | 功能 |
| --- | --- | --- |
| 星球视角 | 左键拖动 / 滚轮 | 旋转视角 / 缩放 |
| 星球视角 | Space | 暂停或继续模拟；输入框编辑时不触发 |
| 游戏中 | P | 启动或暂停；联机要求管理员或作弊权限 |
| 实体交互 | 双击实体 | 进入第一人称视角 |
| 实体视角 | WASD / 鼠标 | 移动 / 转向；移动受有效行动基因限制 |
| 实体视角 | 左键 / Space | 攻击 / 跳跃 |
| 实体视角 | Tab | 返回星球视角 |
| 实体视角 | 按住 Alt / Q | 释放鼠标 / 消耗自身营养吐出能量块（需生效营养利用基因） |
| RTS | R / 左键框选 / 右键 | 切换模式 / 选择实体 / 下达移动或攻击指令 |
| 游戏中 | Esc | 打开菜单：返回游戏、设置、对局域网开放、保存或离开、退出游戏 |
| 暂停面板 | Esc | 返回游戏；设置页面先返回暂停面板 |
| 游戏中 | F10 | 不执行退出或返回主菜单 |

暂停菜单会释放鼠标、屏蔽游戏输入；返回游戏后保留原实体操控目标。

上表为默认按键。在 **设置 → 按键控制** 点击当前按键即可改键，支持鼠标按键、冲突提示和恢复默认，修改自动保存。L切换图层，反引号键取消图层显示，均可改键。游戏数值可直接编辑带中文注释的 [config/gameplay.json](config/gameplay.json)，例如将 `movementMetabolismMultiplier` 改为 `0.5`，行动饱食消耗减半；保存后约2秒自动生效。字段、种群列表及范围显示说明见[按键控制与游戏数值](Docs/操作指南/按键控制与游戏数值.md)。

局域网使用方法及权限见[局域网与 RTS](Docs/操作指南/局域网与RTS.md)。默认端口 47777，房主在世界中按 Esc 开放，成员从主界面“多人游戏”填写 IP、端口及名称加入。

## 存档与自定义配置

编辑器中以工程根目录为基准；Windows 发布版以游戏可执行文件所在目录为基准。

```text
游戏目录/
├─ save/
│  └─ <世界标识>/          # 每个世界一个文件夹
│     ├─ world.json        # 当前世界存档
│     ├─ world.json.bak    # 覆盖保存前的备份
│     └─ legacy.json       # 旧单文件档迁移后保留（如有）
└─ mods/
   └─ Default/
      ├─ Genes/            # 自定义基因 JSON
      ├─ tree.json         # 基因树布局与关系
      └─ entity_states.json # 实体状态注册表，与基因一起导出
```

- 创建新世界时首次保存，默认每 **120 秒**自动保存；保存并返回主界面或退出游戏前也会保存。保存失败会显示错误并留在游戏中。
- 兼容 `save/<世界标识>.json` 旧档；成功写入新目录后，将旧文件和旧备份收纳为 `legacy.json` / `legacy.json.bak`。备份整个世界时复制对应文件夹即可。
- 存档包含世界参数、游戏时间与倍率、暂停状态、星球与太阳相位、相机、实体基因及生命周期状态、收藏和矿量等数据。读取前校验存档，写入时使用临时文件和备份。
- 世界保存自身基因配置快照。旧世界保留已有基因定义，并补齐新版本缺少的基因和相关演化关系；添加页显示全部可用基因，支持滚轮及滚动条。
- 工具入口：**主界面 → 工具 · 基因树编辑器**。“保存并应用”默认写入 `mods/Default`。基因文件名必须与其 JSON 中的 `id` 一致。
- 基因树支持 15%～200% 缩放、缩小/放大按钮、滚轮缩放、中键平移、适应全图和恢复 100%。缩放不改动保存的节点坐标。可拖入节点、移动布局、编辑数值和连线；Shift 左键源节点后再选目标建立下级进化关系，Esc 取消正在建立的关系。
- 实体模板保存在 `templates/entities.json`，带备份，跨世界及重启保留。
- 日志默认保存到游戏目录 `logs`，目录不可写时使用当前用户数据目录；可在设置中打开并一键导出崩溃诊断包（异常堆栈、运行状态、心跳及原生日志）。详见[运行日志与测试](Docs/操作指南/运行日志与测试.md)。
- 本地 `save`、`mods`、`templates`、运行日志和生成的测试产物默认不提交到仓库。分发自定义配置时请另外备份或打包对应文件。

## 开发与验证

改动前请阅读 [项目开发规范](agent.md)。保留 Unity `.meta` 文件，游戏参数优先使用 JSON 或 Inspector 配置；避免在稳定系统中堆叠新功能。

Unity 编辑器提供 **Tools → Darwin Park** 验证入口：

- **Validate World Flow**：从尚未创建世界的启动菜单运行，检查新建、落盘、读档、加载计时、实体、收藏、矿量、备份和坏档拦截。会创建验证世界和本地测试产物。
- **Validate Menu Upgrades**：从尚未加载世界的启动菜单运行，检查每世界独立目录、旧档迁移和备份、保存失败保护、实体操控退出、返回菜单后重进、七基因旧库补齐及添加按钮、缩放坐标。使用独立测试世界，结果位于 `Artifacts/MenuUpgradeReview`。
- **Validate First Person and Gene Tree**：加载世界后检查基因树存储、关系映射，并运行第一人称与生命周期相关回归。
- **Validate Lifecycle and Combat**：生命周期、阶段变异、攻击、繁殖和交互回归。
- **Validate Social Ecology**：从尚未加载世界的启动菜单运行，检查领地驱逐、种群权限与领袖更替、营养守恒、孵化和生态状态存档。
- **Validate Ant Colony**：从尚未加载世界的启动菜单运行，检查巡逻休息与受击反击、出生分工、基因锁定、士兵击杀、工匠运输、补给分配、离群建群、有性配偶及逆序读档；结果位于 `Artifacts/AntColonyReview`。
- **Validate Entity Panel and Motion**：检查基因行图标与布局、活动状态附属分工、王后不可挑战、共有行动属性不重复、1×真实物理移动及体型制约起跳；操作和参数见[实体面板与体型行动](Docs/操作指南/实体面板与体型行动.md)。
- **Validate Entity States**：独立状态标签、严格饱食边界、捕猎者感知、实际追击攻击、配置更改阈值、旧字段迁移、工具导出及世界规则快照往返。
- **Validate Ecology Balance**：实际体型边界、基因调节孕育、生产与储存、行动代谢、多代植物与消费者循环；结果位于 `Artifacts/EcologyBalanceReview`。
- **Capture World Flow**：保存当前菜单或游戏画面及状态。

截至本次更新，解决方案编译通过（0 错误、0 警告），世界新建/保存/读取及 Esc、F10、设置返回和退出前保存已完成 Unity 实机验证。测试产物生成在 `Artifacts` 下；这些开发检查不代表所有平台和所有玩法组合均已验证。

另已完成局域网真实双进程 42 项、发布构建及日志 17 项检查。非开发版 Windows x64 构建成功并实际启动，最终运行日志无错误或异常。构建仅有未登录 Unity Cloud、无法上传原生调试符号的提示。详见[局域网验证](Docs/验证记录/局域网与RTS验证-2026-10-31.md)及[发布构建与日志验证](Docs/验证记录/发布构建与日志验证-2026-10-31.md)。

种群性能自动联合验证入口为 `PopulationPerformanceRegression.RunAllBatch`，覆盖 10/100 成员、多个蚁群、狼群、16× 模拟和关系索引失效，详见[种群性能验证记录](Docs/验证记录/种群性能验证-2026-10-30.md)。

### 重新录制菜单背景

1. 安装 FFmpeg 并确保 `ffmpeg` 可从 `PATH` 找到。
2. 在 Unity 播放模式下先加载一个世界。
3. 执行 **Tools → Darwin Park → Record Menu Background**。

录制会更新 `Assets/StreamingAssets/Menu/earth-orbit.webm` 及封面。当前视频为 **VP8、1280×720、24fps、12 秒循环、无音轨**。
